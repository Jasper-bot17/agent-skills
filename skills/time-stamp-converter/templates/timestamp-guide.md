# 时间戳与时区使用指南

> time-stamp-converter 技能配套指南。

---

## 一、时间戳基础

| 类型 | 位数 | 示例 | 说明 |
|---|---|---|---|
| 秒级时间戳 | 10位 | `1700000000` | 从 1970-01-01 00:00:00 UTC 起的秒数 |
| 毫秒级时间戳 | 13位 | `1700000000000` | 秒级 × 1000 |
| 微秒级时间戳 | 16位 | `1700000000000000` | 秒级 × 1,000,000 |

**自动识别规则**：≥13位视为毫秒，10位视为秒。

## 三、日期格式解析

脚本支持以下日期格式：

```
2024-01-01 00:00:00
2024/1/1 12:30:00
2024年1月1日 12点30分
2024-01-01T00:00:00+08:00  (ISO 8601)
Mon, 01 Jan 2024 00:00:00 +0800  (RFC 2822)
20240101  (紧凑日期)
20240101120000  (紧凑日期时间)
```

## 四、常见使用场景

### 1. 日志时间戳解析
```bash
# 日志中的 13 位毫秒时间戳
python3 convert_ts.py --ts 1699999999999
```

### 2. API 响应时间字段调试
```bash
# 后端返回的时间戳转可读日期
python3 convert_ts.py --ts 1700000000 --timezone UTC
```

### 3. 跨时区会议安排
```bash
# 查看某个时间在各时区的对应时间
python3 convert_ts.py --ts 1700000000 --all-timezones
```

### 4. 批量处理日志文件
```bash
# 从文件批量转换
python3 convert_ts.py --batch timestamps.txt
```

### 5. 计算任务耗时
```bash
# 开始和结束时间戳的差值
python3 convert_ts.py --diff 1700000000 1700100000
```

### 6. 计算截止日期
```bash
# 30天后的时间戳
python3 convert_ts.py --date "2024-01-01" --add-days 30
```

## 五、注意事项

- **夏令时**：使用 IANA 时区标识（如 `America/New_York`）可自动处理夏令时；固定偏移（如 `UTC-5`）不处理夏令时
- **毫秒识别**：13位数字自动识别为毫秒，10位为秒；如不确定可显式指定 `--unit ms`
- **时区数据库**：Python 3.9+ 内置 `zoneinfo`，旧版本可能需要安装 `tzdata` 包
- **2038年问题**：32位系统上秒级时间戳在 2038-01-19 后会溢出，64位系统无此问题
