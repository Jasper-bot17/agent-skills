# 单位换算助手

## 一、技能定位

本技能用于**快速准确地进行各类单位换算**。核心价值：

- 12 大类单位，80+ 种具体单位
- 覆盖公制、英制、中国市制等多种单位制
- 任意单位间直接换算（无需先转基准单位）
- 批量换算：一个值同时换算到该类别所有单位
- 精度控制：自定义小数位数
- 科学计数法：自动处理极大/极小值
- 数据大小：支持二进制（KiB/MiB）和十进制（KB/MB）两种标准
- 温度换算：支持摄氏度、华氏度、开尔文、兰金度、列氏度
- 常用换算速查表

## 四、操作步骤

### 步骤 1：确认需求

确认用户需要：
- 数值（要换算的数值）
- 源单位（从什么单位换算）
- 目标单位（换算到什么单位，可选，不指定则批量换算到所有单位）
- 类别（可选，用于列出该类别所有单位）

### 步骤 2：运行脚本

使用 `scripts/convert_units.py`：

```bash
# 基本用法：直接换算
python3 scripts/convert_units.py --value 1 --from m --to ft

# 批量换算：换算到该类别所有单位
python3 scripts/convert_units.py --value 1 --from m

# 指定类别（列出该类别所有单位）
python3 scripts/convert_units.py --list length

# 列出所有类别
python3 scripts/convert_units.py --categories

# 指定精度（小数位数）
python3 scripts/convert_units.py --value 1 --from km --to mi --precision 4

# 科学计数法显示
python3 scripts/convert_units.py --value 1 --from eV --to J --scientific

# 数据大小换算（二进制）
python3 scripts/convert_units.py --value 1 --from GiB --to MiB

# 数据大小换算（十进制）
python3 scripts/convert_units.py --value 1 --from GB --to MB

# 温度换算
python3 scripts/convert_units.py --value 100 --from C --to F

# 常用换算速查表
python3 scripts/convert_units.py --cheatsheet
```

### 步骤 3：安全提示

1. 本技能只进行数学计算，不修改任何文件
2. 温度换算使用精确公式，非近似值
3. 数据大小换算区分二进制（KiB/MiB/GiB）和十进制（KB/MB/GB）
4. 马赫数随温度和高度变化，脚本使用标准大气（15°C，海平面）下的声速
5. 月和年按固定天数计算（30 天/月，365 天/年），非精确历法
6. 中国市制单位（斤、两、亩、里、丈、尺）使用现代标准定义

## 五、换算公式说明

### 5.1 线性换算
大多数单位通过基准单位进行线性换算：
```
目标值 = (源值 × 源单位到基准的换算因子) / 目标单位到基准的换算因子
```

### 5.2 温度换算（非线性）
温度换算需要偏移量：
- °C → °F：`°F = °C × 9/5 + 32`
- °C → K：`K = °C + 273.15`
- °F → K：`K = (°F + 459.67) × 5/9`
- °C → °R：`°R = (°C + 273.15) × 9/5`
- °C → °Ré：`°Ré = °C × 4/5`

### 5.3 数据大小换算
- 十进制（SI）：`1 KB = 1000 B, 1 MB = 1000 KB, ...`
- 二进制（IEC）：`1 KiB = 1024 B, 1 MiB = 1024 KiB, ...`

## 六、常见场景处理

### 场景 1：学习物理
**用户**：「1 马赫等于多少米每秒？」
**处理**：`--value 1 --from Ma --to m/s` → 约 340.3 m/s。

### 场景 2：出国旅行
**用户**：「今天 75 华氏度，是多少摄氏度？」
**处理**：`--value 75 --from F --to C` → 约 23.89°C。

### 场景 3：购物
**用户**：「这个 5 磅的东西是多少斤？」
**处理**：`--value 5 --from lb --to jin` → 约 4.54 斤。

### 场景 4：计算机存储
**用户**：「1TB 硬盘实际是多少 GB？」
**处理**：`--value 1 --from TB --to GB` → 1000 GB（十进制）；操作系统通常按二进制显示约 931 GiB。

### 场景 5：工程计算
**用户**：「100 马力等于多少千瓦？」
**处理**：`--value 100 --from hp --to kW` → 约 73.55 kW。

### 场景 6：烹饪
**用户**：「烤箱 350 华氏度是多少摄氏度？」
**处理**：`--value 350 --from F --to C` → 约 176.67°C。

### 场景 7：健身
**用户**：「我体重 70 公斤是多少磅？」
**处理**：`--value 70 --from kg --to lb` → 约 154.32 磅。

### 场景 8：能源账单
**用户**：「1 千瓦时等于多少焦耳？」
**处理**：`--value 1 --from kWh --to J` → 3,600,000 J。

## 七、注意事项

1. **精度控制**：默认保留 6 位小数，可通过 `--precision` 调整。
2. **科学计数法**：极大或极小值建议使用 `--scientific` 显示。
3. **温度偏移**：温度换算不是简单的乘法，包含偏移量，脚本已精确处理。
4. **数据大小标准**：注意区分 KB（十进制，1000）和 KiB（二进制，1024）。
5. **马赫数**：马赫数不是固定值，随温度和高度变化，脚本使用标准大气下的声速（340.3 m/s）。
6. **月/年**：月按 30 天、年按 365 天计算，非精确历法（不考虑闰年）。
7. **中国市制**：斤、两、亩、里、丈、尺使用现代标准定义（1 斤=500g，1 亩=666.67m²，1 里=500m，1 丈=10/3m，1 尺=1/3m）。
8. **加仑/夸脱/品脱**：使用美制单位（1 gal=3.78541 L），英制加仑不同（1 gal=4.54609 L）。
9. **马力**：公制马力（1 hp=735.499 W）和英制马力（1 bhp=745.7 W）不同，脚本均支持。
10. **不修改文件**：本技能只进行计算，不创建或修改任何文件。
