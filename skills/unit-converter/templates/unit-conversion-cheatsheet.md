## 三、温度

| 从 | 到 | 换算公式 | 常用参考点 |
|---|---|---|---|
| 摄氏度 (°C) | 华氏度 (°F) | °F = °C × 9/5 + 32 | |
| 华氏度 (°F) | 摄氏度 (°C) | °C = (°F - 32) × 5/9 | |
| 摄氏度 (°C) | 开尔文 (K) | K = °C + 273.15 | |
| 华氏度 (°F) | 开尔文 (K) | K = (°F + 459.67) × 5/9 | |

### 常用温度参考
| 场景 | 摄氏度 | 华氏度 |
|---|---|---|
| 绝对零度 | -273.15°C | -459.67°F |
| 水的冰点 | 0°C | 32°F |
| 冰箱冷藏 | 4°C | 39°F |
| 室温 | 20°C | 68°F |
| 人体体温 | 37°C | 98.6°F |
| 温水（洗澡） | 40°C | 104°F |
| 水的沸点 | 100°C | 212°F |
| 烤箱（烘焙） | 180°C | 350°F |
| 烤箱（高温） | 220°C | 425°F |

### 温度速算
- 摄氏度转华氏度：先乘 2，再加 30（近似）
  - 例：20°C → 20×2+30 = 70°F（实际 68°F）
- 华氏度转摄氏度：先减 30，再除以 2（近似）
  - 例：70°F → (70-30)/2 = 20°C（实际 21.1°C）

## 四、数据大小

### 十进制（SI 标准，厂商常用）
| 单位 | 符号 | 等于字节 |
|---|---|---|
| 千字节 | KB | 1,000 B |
| 兆字节 | MB | 1,000,000 B |
| 吉字节 | GB | 1,000,000,000 B |
| 太字节 | TB | 1,000,000,000,000 B |
| 拍字节 | PB | 10¹⁵ B |

### 二进制（IEC 标准，操作系统常用）
| 单位 | 符号 | 等于字节 |
|---|---|---|
| 千比字节 | KiB | 1,024 B |
| 兆比字节 | MiB | 1,048,576 B |
| 吉比字节 | GiB | 1,073,741,824 B |
| 太比字节 | TiB | 1,099,511,627,776 B |

### 常见疑问
- **为什么 1TB 硬盘只显示 931GB？**
  - 厂商按十进制：1 TB = 1000 GB = 10¹² B
  - 系统按二进制：10¹² B ÷ 1024³ ≈ 931 GiB
  - 所以不是硬盘缩水，是单位标准不同

- **1 GB 等于多少 MB？**
  - 十进制：1 GB = 1000 MB
  - 二进制：1 GiB = 1024 MiB
  - 注意区分 GB 和 GiB

- **网速 100Mbps 是多少 MB/s？**
  - 100 Mbps = 100 兆比特每秒
  - 1 字节 = 8 比特
  - 100 Mbps ÷ 8 = 12.5 MB/s
