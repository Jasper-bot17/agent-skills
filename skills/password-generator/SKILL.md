# 密码生成与强度检测助手

## 一、技能定位

本技能用于**生成安全密码和评估密码强度**。核心价值：

- 使用密码学安全的随机数生成器（`secrets` 模块）
- 多种密码类型：随机密码、易记口令、PIN码
- 科学的强度评估：熵值计算 + 常见密码检测 + 字符多样性
- 策略合规检查：自定义密码策略并验证

## 二、触发场景

当用户出现以下需求时使用本技能：

1. 用户说「帮我生成一个密码」「给我一个强密码」
2. 用户说「帮我生成一个好记的密码」「要能记住的」
3. 用户说「这个密码安全吗」「帮我看看这个密码强度」
4. 用户说「生成一个 6 位 PIN 码」「生成验证码」
5. 用户说「批量生成 10 个密码」
6. 用户说「检查这个密码是否符合策略」
7. 用户说「生成一个符合 XX 要求的密码」

## 三、支持的密码类型

### 3.1 随机密码（Random Password）

- 使用 `secrets` 模块（密码学安全）
- 可定制长度（默认 16 位）
- 可选字符集：大写字母、小写字母、数字、特殊符号
- 可排除易混淆字符（0/O, 1/l/I, 5/S 等）

### 3.2 易记口令（Passphrase）

- 基于单词组合，如 `Correct-Horse-Battery-Staple`
- 可定制单词数量（默认 4 个）
- 支持分隔符自定义（默认 `-`）
- 可选择是否首字母大写
- 熵值远高于普通短密码

### 3.3 PIN 码

- 纯数字密码
- 可定制长度（默认 6 位）
- 可选择是否允许重复数字
- 可选择是否允许连续数字（如 123456）

## 四、强度评估

### 4.1 评估维度

| 维度 | 说明 |
|---|---|
| 熵值（Entropy） | 基于字符集大小和长度计算，单位 bits |
| 长度 | 密码长度评分 |
| 字符多样性 | 是否包含大小写、数字、符号 |
| 常见密码检测 | 是否在常用密码列表中 |
| 模式检测 | 是否包含连续字符、重复字符、键盘序列 |

### 4.2 强度等级

| 等级 | 熵值 | 说明 |
|---|---|---|
| 🔴 极弱 | < 28 bits | 极易被破解，不建议使用 |
| 🟠 弱 | 28-35 bits | 可被快速破解 |
| 🟡 中等 | 36-59 bits | 日常使用可接受 |
| 🟢 强 | 60-127 bits | 安全性良好 |
| 🔵 极强 | ≥ 128 bits | 极高安全性 |

### 4.3 常见密码检测

内置常见弱密码列表（100+ 个），包括：
- `password`, `123456`, `qwerty`, `admin` 等
- 检测到后直接标记为「极弱」

## 五、策略合规检查

可自定义密码策略并验证：

| 策略项 | 说明 |
|---|---|
| 最小长度 | 如至少 8 位 |
| 最大长度 | 如最多 64 位 |
| 必须包含大写 | 至少一个 A-Z |
| 必须包含小写 | 至少一个 a-z |
| 必须包含数字 | 至少一个 0-9 |
| 必须包含符号 | 至少一个特殊字符 |
| 禁止常见密码 | 不允许使用弱密码 |

## 六、操作步骤

### 步骤 1：确认需求

确认用户需要：
- 生成密码 / 评估密码强度 / 检查策略合规
- 密码类型（随机/口令/PIN）
- 长度和字符集要求
- 数量（单个或批量）

### 步骤 2：运行脚本

使用 `scripts/generate_password.py`：

```bash
# 生成默认随机密码（16位，含大小写数字符号）
python3 scripts/generate_password.py

# 生成长度为 20 的密码
python3 scripts/generate_password.py --length 20

# 只包含字母和数字
python3 scripts/generate_password.py --no-symbols

# 排除易混淆字符
python3 scripts/generate_password.py --no-ambiguous

# 生成易记口令（4个单词）
python3 scripts/generate_password.py --type passphrase

# 生成 6 位 PIN 码
python3 scripts/generate_password.py --type pin --length 6

# 批量生成 10 个密码
python3 scripts/generate_password.py --count 10

# 评估密码强度
python3 scripts/generate_password.py --check "MyP@ssw0rd!"

# 检查策略合规
python3 scripts/generate_password.py --check "MyP@ssw0rd!" --policy min-length=12,require-upper,require-number,require-symbol

# 输出到文件
python3 scripts/generate_password.py --count 20 --output passwords.txt
```

### 步骤 3：解读结果

- **生成模式**：输出生成的密码及强度评估
- **检查模式**：输出密码强度详情和策略合规结果
- **批量模式**：输出多个密码，可保存到文件

### 步骤 4：安全提示

1. 生成的密码应立即使用，不要明文存储
2. 建议使用密码管理器保存
3. 不同账号使用不同密码
4. 定期更换重要账号密码

## 九、注意事项

1. **安全生成**：使用 Python `secrets` 模块（密码学安全随机数），不使用 `random`。
2. **不存储密码**：生成的密码仅输出到终端或指定文件，不记录到任何日志。
3. **常见密码列表**：内置 100+ 常见弱密码，检测到直接标记为极弱。
4. **熵值计算**：基于字符集大小 × 长度，实际熵值可能因模式（重复、连续）而降低。
5. **PIN 码安全性**：纯数字 PIN 熵值较低，仅适合本地设备解锁，不适合网络账号。
6. **易记口令**：单词数量建议 ≥ 4，每个单词 ≥ 5 个字母，安全性才足够。
7. **特殊符号**：默认使用 `!@#$%^&*()-_=+[]{}|;:,.<>?`，部分系统可能不支持某些符号。
8. **不提供已泄露密码查询**：本技能不调用外部 API 检查密码是否已泄露，如需查询请使用 Have I Been Pwned 等服务。
9. **隐私保护**：所有生成本地完成，密码不离开本地环境。
10. **使用建议**：生成后建议立即复制使用，不要截屏或明文保存。
