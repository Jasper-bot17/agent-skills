# 习惯养成指南

> habit-tracker 技能配套指南。

---

## 一、21天习惯养成法

- 一个新习惯的养成平均需要 **66 天**（不是21天）
- 关键不是完美打卡，而是 **尽量不断**
- 断了一天没关系，断两天以上才会降低成功率

---

## 二、推荐追踪的习惯分类

### 健康类
- 早起 / 早睡
- 运动30分钟
- 喝水8杯
- 吃早餐
- 不喝奶茶

### 学习类
- 阅读30分钟
- 背单词20个
- 写日记
- 复习笔记
- 学编程1小时

### 效率类
- 列每日待办
- 不刷手机超过1小时
- 23点前睡觉
- 每天复盘

---

## 三、使用建议

1. **从1-3个习惯开始**，不要一次加太多
2. **小到不可能失败**：比如"做1个俯卧撑"比"健身1小时"更容易坚持
3. **固定时间**：把习惯绑定到已有动作上（如"刷牙后喝水"）
4. **打卡公开**：告诉朋友或写在显眼处
5. **每周回顾**：用 `week` 命令看本周完成情况
6. **允许断签**：streak 断了就从今天重新开始，不要放弃

---

## 四、常用命令速查

```bash
# 添加习惯
python3 habit_tracker.py add "习惯名" -c "分类"

# 今日打卡
python3 habit_tracker.py check "习惯名"

# 看仪表盘
python3 habit_tracker.py dashboard

# 看本周
python3 habit_tracker.py week

# 看本月
python3 habit_tracker.py month
```
