# 文件整理助手

## 一、技能定位

本技能用于**自动化扫描、分类和整理本地文件目录**。核心价值：

- 自动识别文件类型并分类统计，无需手动逐个查看
- 识别大文件、重复文件、长期未使用文件，精准定位空间占用
- 生成可预览的整理方案（dry-run），确认后再执行，避免误操作
- 支持多种整理策略：按类型、按日期、按项目、自定义规则
- 生成整理报告，记录移动/删除/归档的文件清单

## 二、触发场景

当用户出现以下需求时使用本技能：

1. 用户说「帮我整理一下下载文件夹」「桌面太乱了，帮我收拾一下」
2. 用户说「这个目录里文件太多了，帮我分类整理」
3. 用户说「帮我看看哪些文件占空间大」「找出大文件」「清理磁盘空间」
4. 用户说「帮我找出重复文件」「这些文件有没有重复的」
5. 用户说「帮我把文件按日期归档」「按类型分文件夹」
6. 用户说「这个目录里有什么文件」「帮我分析一下这个文件夹的内容」
7. 用户说「清理一下临时文件」「删除没用的文件」

## 四、操作步骤

### 步骤 1：确认整理范围和安全边界

1. 确认用户要整理的目录路径（必须是明确的绝对路径或相对路径）
2. 确认整理范围：仅当前目录 / 递归子目录 / 排除某些子目录
3. 确认操作模式：
   - **仅分析**：只扫描统计，不移动/删除任何文件
   - **预览（dry-run）**：生成整理方案，展示将移动/删除的文件，但不实际执行
   - **执行**：实际移动/删除文件（需用户明确确认）
4. **安全检查**：
   - 禁止整理系统关键目录（`/`, `/usr`, `/etc`, `/bin`, `/sbin`, `/var` 等）
   - 禁止整理当前工作目录的上级目录（避免误操作）
   - 删除操作必须二次确认，且默认先移到回收站/临时目录而非直接删除
   - 隐藏文件（`.` 开头）默认不移动，除非用户明确要求

### 步骤 2：扫描目录并生成统计

使用 `scripts/organize_files.py` 扫描目录：

```bash
# 仅分析（统计分类、大小、大文件）
python3 scripts/organize_files.py --dir /path/to/folder --mode analyze

# 预览整理方案（dry-run，不实际移动）
python3 scripts/organize_files.py --dir /path/to/folder --mode dry-run --strategy type

# 执行整理（按类型分类）
python3 scripts/organize_files.py --dir /path/to/folder --mode execute --strategy type

# 按日期归档
python3 scripts/organize_files.py --dir /path/to/folder --mode dry-run --strategy date

# 找出大文件（>100MB）
python3 scripts/organize_files.py --dir /path/to/folder --mode analyze --large-threshold 100

# 排除特定目录
python3 scripts/organize_files.py --dir /path/to/folder --mode analyze --exclude node_modules,.git,__pycache__
```

扫描结果包含：
- 文件总数、总大小、目录数
- 按类型分类的文件数量和占用空间
- Top 10 大文件
- 按修改时间分布（最近7天/30天/90天/90天以上）
- 重复文件检测（基于文件大小+MD5，可选）
- 长期未使用文件（>90天未访问，可选）

### 步骤 3：选择整理策略

根据扫描结果和用户需求，选择整理策略：

| 策略 | 说明 | 适用场景 |
|---|---|---|
| `type`（按类型） | 创建 `文档/`、`图片/`、`视频/` 等子目录，按文件类型移动 | 通用整理、下载文件夹、桌面 |
| `date`（按日期） | 创建 `2024-01/`、`2024-02/` 等子目录，按修改日期归档 | 照片归档、长期文件归档 |
| `type-date`（类型+日期） | 先按类型分，类型内再按日期分 | 大量混合文件的深度整理 |
| `project`（按项目） | 根据文件名关键词或用户指定规则分组 | 项目文件整理 |
| `custom`（自定义） | 用户自定义分类规则 | 特殊需求 |

### 步骤 4：生成整理方案并预览

1. 基于选择的策略，生成每个文件的目标路径
2. 处理文件名冲突：
   - 同名文件自动重命名（`filename (1).ext`、`filename (2).ext`）
   - 或提示用户选择覆盖/跳过/重命名
3. 生成整理方案摘要：
   - 将移动的文件数量和总大小
   - 将创建的目录列表
   - 每个分类的文件数量
   - 预计释放/整理的空间
4. **以 dry-run 模式展示方案**，列出将移动的文件（或前 50 个，超出部分汇总）
5. 请用户确认后再执行

### 步骤 5：执行整理（需用户确认）

1. 用户明确确认后，切换到 `execute` 模式
2. 按方案创建目标目录
3. 逐个移动文件（使用 `shutil.move`，跨文件系统也能处理）
4. 记录每个文件的操作结果（成功/失败/跳过）
5. 处理失败文件：记录原因，不中断整体流程
6. 执行完成后，生成整理报告

## 六、常见场景处理

### 场景 1：整理下载文件夹
**用户**：「帮我整理一下 ~/Downloads」
**处理**：扫描 → 按类型分类 → dry-run 预览 → 用户确认 → 执行 → 生成报告。默认排除 `.app`、`.dmg` 等已安装的安装包（可提示是否删除）。

### 场景 2：清理桌面
**用户**：「桌面太乱了，帮我收拾一下」
**处理**：扫描桌面 → 识别快捷方式/文件/文件夹 → 按类型分类 → 注意保留系统文件和快捷方式 → dry-run → 执行。

### 场景 3：找出大文件释放空间
**用户**：「磁盘快满了，帮我找出大文件」
**处理**：扫描指定目录（如 home 目录）→ 按大小排序 → 列出 Top 20 大文件 → 标注文件类型和最后修改时间 → 建议可删除/归档的文件 → 用户确认后处理。

### 场景 4：照片按日期归档
**用户**：「帮我把这些照片按日期整理」
**处理**：扫描图片目录 → 优先读取 EXIF 拍摄日期，无 EXIF 则用修改日期 → 创建 `YYYY-MM/` 目录 → 移动照片 → dry-run → 执行 → 报告。

### 场景 5：检测重复文件
**用户**：「帮我看看这个目录里有没有重复的文件」
**处理**：扫描目录 → 先按文件大小分组（大小相同才可能重复）→ 对大小相同的文件计算 MD5 → 列出重复文件组 → 建议保留最新/最大/路径最短的版本 → 用户确认后删除多余副本。

### 场景 6：清理临时/缓存文件
**用户**：「帮我清理一下临时文件和缓存」
**处理**：扫描常见临时目录（`/tmp`、`~/.cache`、项目的 `node_modules`、`__pycache__`、`.git` 等）→ 统计可清理空间 → 列出将删除的内容 → 用户确认 → 删除（或移到回收站）→ 报告释放空间。

## 七、安全规则

### 7.1 绝对禁止
- 禁止整理或删除系统关键目录（`/`, `/usr`, `/etc`, `/bin`, `/sbin`, `/lib`, `/var`, `/boot`, `/dev`, `/proc`, `/sys`）
- 禁止删除用户主目录下的隐藏配置文件（`.bashrc`, `.profile`, `.ssh`, `.config` 等），除非用户明确要求
- 禁止在未确认的情况下执行删除操作
- 禁止跨用户目录操作（如从 `/home/user1` 移到 `/home/user2`）

### 7.2 默认安全策略
- **删除 = 移动到回收站**：默认将"删除"的文件移到 `~/.Trash/` 或临时目录，而非直接 `rm`
- **dry-run 优先**：所有移动/删除操作先预览，用户确认后再执行
- **隐藏文件保护**：`.` 开头的文件默认不移动、不删除
- **文件名冲突**：遇到同名文件自动重命名，不覆盖
- **操作日志**：记录所有移动/删除操作，可回滚（生成 undo 脚本）
- **大小阈值**：单个文件 > 1GB 或总操作 > 5GB 时，额外提醒用户确认

### 7.3 回滚机制
- 每次执行整理时，生成 `undo_YYYYMMDD_HHMMSS.sh` 脚本
- 脚本记录所有移动操作的源路径和目标路径
- 用户可运行该脚本将文件移回原位
- 回滚脚本保存在整理目录的 `.file-organizer-backup/` 下

## 八、注意事项

1. **路径确认**：整理前必须确认目录路径正确，避免整理错误目录。
2. **权限检查**：如目录需要管理员权限，提示用户，不擅自使用 `sudo`。
3. **大文件处理**：移动大文件（>1GB）可能耗时较长，告知用户预计时间。
4. **跨文件系统**：源和目标在不同磁盘/分区时，移动 = 复制+删除，耗时更长且需要足够空间。
5. **文件占用**：被其他程序占用的文件可能无法移动，记录并跳过。
6. **符号链接**：默认不跟随符号链接，避免循环引用和误操作。
7. **空目录处理**：整理后留下的空目录，可提示用户是否删除。
8. **不替代专业工具**：本技能适用于常规文件整理，不替代专业的数据恢复、磁盘分区等工具。
9. **隐私保护**：整理过程中不读取文件内容，仅基于文件名、扩展名、大小、时间等元数据操作。
10. **操作不可逆提醒**：虽然提供回滚脚本，但删除（移到回收站）的文件可能被系统清理，重要文件建议先备份。
