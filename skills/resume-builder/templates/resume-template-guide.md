# 简历写作指南与模板说明

> resume-builder 技能配套的简历写作指南，帮助用户写出高质量简历。

---

## 一、简历写作原则

### 1. 一页原则
- 应届生和 3 年以内经验：控制在 1 页
- 3-10 年经验：1-2 页
- 10 年以上或高管：2 页以内

### 2. 倒序排列
- 工作经历、教育背景、项目经验均按时间倒序排列
- 最近的经历放在最前面

### 3. 量化成果
- 用数字说话，避免空泛描述
- 差："优化了系统性能"
- 好："优化数据库查询，核心接口响应时间从 800ms 降低至 120ms"

### 4. 动词开头
- 每条经历描述以动词开头：主导、设计、实现、优化、推动、负责
- 英文简历使用过去式动词：Led, Designed, Implemented, Optimized

### 5. 关键词匹配
- 研究目标岗位的 JD（职位描述）
- 在简历中自然融入 JD 中的关键词
- 技能部分列出与岗位相关的技术栈

---

## 二、各部分写作要点

### 个人信息（personal）
- 姓名：清晰醒目
- 电话：确保可联系
- 邮箱：使用专业邮箱（避免 qq 数字邮箱，建议姓名拼音邮箱）
- 所在地：城市即可，不需要详细地址
- GitHub/个人网站：技术岗位强烈建议附上

### 求职意向（objective）
- 目标职位：明确具体，如"高级后端开发工程师"
- 个人简介：3-4 句话，突出核心优势和经验年限
- 不要写"希望获得一份有挑战性的工作"等空话

### 工作经历（experience）
- 公司名 + 职位 + 时间 + 地点
- 描述 3-5 条，按重要性排序
- 每条描述：做了什么 + 怎么做的 + 结果如何（量化）
- 最近的工作经历描述可以详细一些，较早的经历可以简略

### 教育背景（education）
- 学校 + 学位 + 专业 + 时间
- GPA：3.5/4.0 以上建议写，以下不写
- 应届生可写相关课程、毕业设计
- 工作 5 年以上可简化教育背景

### 技能（skills）
- 按分类组织：编程语言、框架、数据库、工具等
- 只写真正掌握的技能，面试会被追问
- 熟练度可用：精通、熟练、了解 或 熟练使用、有使用经验
- 与目标岗位相关的技能放前面

### 项目经验（projects）
- 项目名 + 角色 + 时间
- 技术栈：列出使用的关键技术
- 描述：项目背景 + 个人职责 + 技术亮点 + 成果
- 有 GitHub 链接或线上 Demo 一定要附上

### 证书（certifications）
- 只写与目标岗位相关的证书
- 写明证书名称和颁发机构
- 过期证书不要写

### 语言能力（languages）
- 母语 + 外语水平
- 英语可写：CET-4/6、雅思、托福分数
- 有海外经历可注明

## 三、三种模板风格适用场景

| 风格 | 特点 | 适用场景 |
|---|---|---|
| **classic（经典）** | 传统排版，分隔线清晰，信息完整 | 传统行业、国企、社招正式简历 |
| **concise（简洁）** | 紧凑布局，减少空行，突出重点 | 应届生、实习、一页纸简历、网申 |
| **modern（现代）** | 渐变色、卡片式、标签化技能 | 互联网、设计、创意岗位、前端开发 |

---

## 四、中英文简历差异

| 方面 | 中文简历 | 英文简历（CV/Resume） |
|---|---|---|
| 照片 | 通常需要 | 通常不需要（避免歧视） |
| 个人信息 | 可写年龄、性别、政治面貌 | 只写姓名、联系方式 |
| 长度 | 1-2 页 | 1 页（经验少）/ 2 页（经验丰富） |
| 日期格式 | 2020.03 - 至今 | Mar 2020 - Present |
| 描述风格 | 可较详细 | 简洁，动词开头，量化成果 |
| 技能描述 | 精通/熟练/了解 | Proficient / Familiar with |

---

## 五、常见错误

1. **错别字和语法错误**：投递前务必仔细检查
2. **时间线矛盾**：确保工作和教育时间不重叠、无空白期未解释
3. **信息过时**：电话、邮箱、GitHub 链接确保有效
4. **过于花哨**：除非设计岗位，否则简洁专业更好
5. **编造经历**：面试会深挖，诚实为上策
6. **缺少量化**：通篇"负责XX"但没有成果数据
7. **针对性不足**：一份简历投所有岗位，应根据 JD 调整

## 六、JSON 数据模板

最小可用的简历 JSON 结构：

```json
{
  "personal": {
    "name": "姓名",
    "email": "email@example.com",
    "phone": "138-0000-0000"
  },
  "objective": {
    "position": "目标职位",
    "summary": "个人简介"
  },
  "experience": [
    {
      "company": "公司名",
      "position": "职位",
      "start_date": "2020-01",
      "end_date": "至今",
      "description": ["工作描述1", "工作描述2"]
    }
  ],
  "education": [
    {
      "school": "学校",
      "degree": "学位",
      "major": "专业",
      "start_date": "2016-09",
      "end_date": "2020-06"
    }
  ],
  "skills": [
    {
      "category": "分类",
      "items": ["技能1", "技能2"]
    }
  ]
}
```
