# 色彩理论参考与配色指南

> 理解色彩基础，做出更好的配色决策。

## 一、色彩基础

### 1.1 颜色三要素

| 要素 | 说明 | 范围 |
|---|---|---|
| 色相（Hue） | 颜色的基本相貌（红、绿、蓝等） | 0° - 360° |
| 饱和度（Saturation） | 颜色的鲜艳程度 | 0% - 100% |
| 明度（Lightness/Value） | 颜色的明暗程度 | 0% - 100% |

### 1.2 常用颜色空间

- **RGB**：加色模型，用于屏幕显示（红+绿+蓝=白）
- **CMYK**：减色模型，用于印刷（青+品红+黄+黑）
- **HSL**：色相-饱和度-明度，直观易用
- **HSV**：色相-饱和度-明度，与 HSL 算法不同
- **HEX**：十六进制表示，网页开发最常用

## 二、色轮与配色方案

### 2.1 色轮基础

```
          0° 红
         /    \
   300° 品红  60° 黄
       |        |
   240° 蓝    120° 绿
         \    /
          180° 青
```

### 2.2 六种经典配色方案

| 方案 | 角度关系 | 特点 | 适用场景 |
|---|---|---|---|
| 互补色 | 180° | 对比强烈，视觉冲击 | 按钮、强调色、CTA |
| 类比色 | ±30° | 和谐统一，自然舒适 | 背景、大面积色块 |
| 三角色 | 120° | 平衡活泼，色彩丰富 | 品牌主色、插画 |
| 四角色 | 90° | 多彩多变，层次丰富 | 复杂界面、数据可视化 |
| 分裂互补 | 150°/210° | 比互补柔和，仍有对比 | 比互补色更易驾驭 |
| 单色渐变 | 同色相 | 简约高级，统一感强 | 极简设计、按钮状态 |

## 三、无障碍设计（WCAG）

### 3.1 对比度标准

| 等级 | 普通文本 | 大文本 |
|---|---|---|
| AA（最低） | ≥ 4.5:1 | ≥ 3:1 |
| AAA（最高） | ≥ 7:1 | ≥ 4.5:1 |

**大文本定义**：18pt（约 24px）以上，或 14pt（约 18.66px）粗体以上。

### 3.2 对比度计算公式

```
相对亮度 L = 0.2126 × R + 0.7152 × G + 0.0722 × B
（R/G/B 需先做 gamma 校正：sRGB ≤ 0.03928 时线性，否则 ((sRGB+0.055)/1.055)^2.4）

对比度 = (L_light + 0.05) / (L_dark + 0.05)
```

### 3.3 常见配色对比度参考

| 前景 | 背景 | 对比度 | AA普通 | AA大文本 |
|---|---|---|---|---|
| 白色 #FFF | 深蓝 #0D47A1 | 12.6 | ✅ | ✅ |
| 白色 #FFF | 蓝色 #2196F3 | 4.5 | ✅ | ✅ |
| 白色 #FFF | 浅蓝 #90CAF9 | 1.8 | ❌ | ❌ |
| 黑色 #000 | 黄色 #FFEB3B | 19.5 | ✅ | ✅ |
| 黑色 #000 | 浅灰 #BDBDBD | 8.5 | ✅ | ✅ |
| 白色 #FFF | 红色 #F44336 | 4.0 | ❌ | ✅ |

## 四、配色实践建议

### 4.1 60-30-10 法则

- **60%** 主色（背景、大面积）
- **30%** 辅助色（侧边栏、卡片）
- **10%** 强调色（按钮、链接、CTA）

### 4.2 数据可视化配色

- 分类数据：使用区分度高的定性色板（如 Tableau 10 色）
- 顺序数据：使用单色渐变（浅→深）
- 发散数据：使用双色渐变（如红→白→蓝）
- 色盲友好：避免红绿组合，使用蓝橙组合

### 4.3 深色模式配色

- 背景：深灰（#121212）而非纯黑，减少视觉疲劳
- 表面：比背景亮 5-10%（#1E1E1E, #2A2A2A）
- 文字：高亮度灰白（#E0E0E0）而非纯白
- 主色：降低饱和度（如 #64B5F6 而非 #2196F3）

### 4.4 品牌配色

- 选择 1 个主色代表品牌个性
- 搭配 1-2 个辅助色增加层次
- 准备 5-10 个色阶（50-900）用于不同场景
- 确保主色在白底和深底上都有足够对比度
