# Markdown 排版规范

> 本规范用于指导 Markdown 文档的格式化和排版。

---

## 一、标题规范

1. 文档以一个 H1（`#`）开头，作为文档标题
2. 标题层级不跳跃（H1 → H2 → H3，不跳过 H2 直接到 H3）
3. `#` 后必须加一个空格：`# 标题`，不是 `#标题`
4. 标题前后各留一个空行
5. 同一层级不使用重复标题

```markdown
# 文档标题

## 第一节

### 1.1 小节

## 第二节
```

---

## 二、表格规范

1. 表格列宽对齐，便于阅读
2. 表头与数据之间必须有分隔行（`|---|`）
3. 所有行列数一致
4. 分隔行可指定对齐方式：`:---`（左对齐）、`:---:`（居中）、`---:`（右对齐）

```markdown
| 名称   | 类型   | 说明       |
| ------ | ------ | ---------- |
| 张三   | 学生   | 计算机专业 |
| 李四   | 教师   | 教数学     |
```

---

## 三、代码块规范

1. 代码块必须指定语言：```python，不是 ```
2. 代码块必须闭合（前后各三个反引号）
3. 行内代码用单个反引号：`code`

---

## 四、链接规范

1. 链接格式：`[链接文字](URL)`
2. 链接不能为空：`[文字]()` 是错误的
3. 本地文件链接应确保文件存在
4. 图片格式：`![替代文字](图片URL)`

---

## 五、列表规范

1. 无序列表用 `-` 或 `*`，全文统一
2. 有序列表用 `1.` `2.` `3.`
3. 列表项缩进一致（2或4个空格）
4. 列表项之间可以有空行

---

## 六、其他规范

1. 段落之间留一个空行
2. 行尾不留多余空格
3. 引用用 `>` 开头
4. 粗体用 `**文字**`，斜体用 `*文字*`
5. 水平线用 `---`（前后留空行）

---

*规范由 markdown-formatter 技能维护*
