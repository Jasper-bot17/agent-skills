# 项目说明文档

##简介

这是一个示例项目，用于演示 Markdown 格式化。

### 功能特性

- 自动对齐表格
- 生成文档目录
- 检查语法问题

##安装

###依赖

需要 Python 3.8+

###配置

编辑 config.yaml 文件

##使用方法

###基本用法

```
python main.py --input data.csv
```

###高级选项

|选项|说明|默认值|
|---|---|---|
|--input|输入文件路径|data.csv|
|--output|输出文件路径|output.csv|
|--verbose|详细输出|false|
