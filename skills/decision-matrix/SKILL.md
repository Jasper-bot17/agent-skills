# 决策矩阵助手（加权评分法）

## 触发场景

当用户出现以下意图时使用本技能：

- "帮我做个决策"
- "选 A 还是选 B"
- "这几个工作机会怎么选"
- "哪个房子更值得租"
- "帮我比较几个方案"
- "加权评分"
- "决策矩阵"
- "多标准决策"
- "哪个选项更好"

## 核心功能

| 功能 | 说明 |
|---|---|
| 多标准评分 | 为每个选项按多个标准打分（1-10） |
| 权重设置 | 每个标准有权重（1-10 分或百分比），权重自动归一化 |
| 加权总分 | 自动计算每个选项的加权总分 |
| 排名 | 按总分降序排列，标注推荐选项 |
| 对比表格 | 文本表格展示所有选项和标准的得分 |
| 敏感性分析 | 调整某个权重后，观察排名变化 |
| JSON 输出 | 便于程序调用 |
| 逆向标准 | 支持"成本越低越好"等逆向标准（得分自动反向） |

## 使用方法

### 命令行工具

```bash
# 基本用法：交互式输入
python3 scripts/decision_matrix.py

# 通过 JSON 配置文件运行
python3 scripts/decision_matrix.py --config decision.json

# 敏感性分析：调整某个权重
python3 scripts/decision_matrix.py --config decision.json --sensitivity "薪资=15"

# JSON 输出
python3 scripts/decision_matrix.py --config decision.json --json
```

### JSON 配置格式

```json
{
  "title": "选择工作机会",
  "criteria": [
    {"name": "薪资", "weight": 8, "direction": "positive"},
    {"name": "通勤时间", "weight": 5, "direction": "negative"},
    {"name": "团队氛围", "weight": 7, "direction": "positive"},
    {"name": "成长空间", "weight": 9, "direction": "positive"}
  ],
  "options": [
    {
      "name": "公司 A",
      "scores": {"薪资": 8, "通勤时间": 6, "团队氛围": 7, "成长空间": 8}
    },
    {
      "name": "公司 B",
      "scores": {"薪资": 7, "通勤时间": 8, "团队氛围": 9, "成长空间": 7}
    },
    {
      "name": "公司 C",
      "scores": {"薪资": 9, "通勤时间": 4, "团队氛围": 5, "成长空间": 9}
    }
  ]
}
```

### 作为模块调用

```python
from decision_matrix import DecisionMatrix

dm = DecisionMatrix(
    criteria=[("薪资", 8, "positive"), ("通勤", 5, "negative")],
    options=[
        ("公司A", {"薪资": 8, "通勤": 6}),
        ("公司B", {"薪资": 7, "通勤": 8}),
    ]
)
results = dm.calculate()
for r in results:
    print(f"{r['name']}: {r['total_score']:.1f}")
```

## 操作步骤

1. **明确决策问题**：用户要在什么选项之间做选择
2. **确定评价标准**：列出用户关心的维度（如薪资、通勤、氛围等）
3. **设置权重**：每个标准的重要程度（1-10）
4. **为每个选项打分**：按每个标准给选项打分（1-10）
5. **计算加权总分**：自动计算并排名
6. **展示结果**：对比表格 + 推荐 + 敏感性分析

## 评分原则

- **正向标准**（越大越好）：如薪资、成长空间 → 得分越高越好
- **逆向标准**（越小越好）：如通勤时间、成本 → 得分 = 11 - 原始分（自动反向）
- 权重范围：1-10，程序自动归一化为百分比
- 建议标准数量：3-7 个，太多会增加决策复杂度

## 输出规范

- 标题和决策问题
- 标准列表（含权重）
- 选项对比表格（行=选项，列=标准）
- 加权总分和排名
- 推荐选项标注
- 敏感性分析（如果指定）
- 结论和建议
