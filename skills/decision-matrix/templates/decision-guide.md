# 决策矩阵使用指南

> decision-matrix 技能配套指南。

---

## 一、什么是决策矩阵

决策矩阵（加权评分法）是一种结构化决策工具：当面临多个选项、多个评价标准时，为每个标准设置权重，为每个选项按标准打分，计算加权总分来量化比较。

**核心思想**：把"我感觉哪个好"变成"按各维度算出来哪个好"。

---

## 二、适用场景

| 场景 | 典型标准 |
|---|---|
| 选工作 | 薪资、通勤、团队氛围、成长空间、福利 |
| 选房子 | 租金、通勤、面积、采光、周边配套 |
| 选产品 | 价格、性能、品牌、售后、外观 |
| 选学校 | 排名、专业匹配、地理位置、学费、就业 |
| 项目选型 | 成本、工期、风险、可维护性、团队熟悉度 |

---

## 三、评分原则

### 权重设置（1-10）

- 5：一般重要
- 7：比较重要
- 9：非常重要（决定性因素）
- 程序自动归一化，权重间比例正确即可

### 选项评分（1-10）

| 分数 | 含义 |
|---|---|
| 9-10 | 非常好，远超预期 |
| 7-8 | 比较好，明显优势 |
| 5-6 | 一般，中规中矩 |
| 3-4 | 比较差，有明显不足 |
| 1-2 | 很差，不可接受 |

### 方向设置

- **正向（↑）**：越大越好，如薪资、性能
- **逆向（↓）**：越小越好，如通勤时间、成本、价格
- 逆向标准自动反向计分（原始分4=距离近=好）

---

## 四、敏感性分析

如果某个标准权重变化会导致推荐选项翻转，说明：

1. **结果不稳健**：决策对该维度很敏感
2. **需要更多信息**：在翻转的关键维度上做深入调查
3. **主观因素影响大**：权重设置可能反映了个人偏好而非实际重要性

**建议**：对排名接近的选项（分差 < 1分），一定要做敏感性分析。

---

## 五、决策步骤

1. **列出所有选项**（不要遗漏，至少2个）
2. **确定评价标准**（3-7个，太多会分散注意力）
3. **给标准分配权重**（基于你最在意什么）
4. **为每个选项打分**（客观、诚实，不要因为偏好先入为主）
5. **查看结果**：总分最高的选项
6. **敏感性分析**：关键权重变化是否翻转结果
7. **综合判断**：量化结果是参考，不是最终结论

---

## 六、常见误区

1. **权重和分数趋同**：所有标准权重差不多 = 没有重点
2. **先选结果再打分**：已经决定选A，然后给A高分 = 自欺欺人
3. **标准太多**：10个以上标准 = 决策瘫痪
4. **忽略逆向标准**：价格越低越好，但忘了设逆向方向
5. **不做敏感性分析**：分差很小就认为结果确定
6. **完全依赖工具**：矩阵辅助理性思考，但不能替代直觉和经验
