❌ 错误 1/7（语法错误）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 位置：main.cpp:5:18
📝 原始：error: expected ';' before '}' token
💡 中文解释：
  缺少分号。编译器在遇到某个标记时期望前面有分号结尾，通常是上一行语句忘记写分号。
🔧 修复建议：
  检查错误位置附近的语句，确保每条语句以分号结尾。特别注意上一行。
📝 代码示例：
  错误：int x = 5    // 缺少分号
  正确：int x = 5;   // 加上分号

❌ 错误 2/7（声明错误）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 位置：main.cpp:8:5
📝 原始：error: 'cout' was not declared in this scope
💡 中文解释：
  变量或函数在当前作用域中未声明。可能的原因：①变量名拼写错误；②变量在其他作用域（如函数内）声明；③缺少 using 声明；④标准库对象缺少 std:: 前缀。
🔧 修复建议：
  1. 检查变量名拼写是否正确
  2. 确认变量声明的作用域是否包含使用位置
  3. 如果是标准库对象（cout/cin/string等），确保包含对应头文件并使用 std:: 前缀
📝 代码示例：
  错误：cout << "hello";   // 缺少 std:: 前缀
  正确：std::cout << "hello";

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 位置：main.cpp:12:9
📝 原始：warning: unused variable 'y' [-Wunused-variable]
💡 中文解释：
  变量声明了但从未使用。可能是忘记使用，也可能是调试时遗留的代码。
🔧 修复建议：
  如果确实不需要，删除该变量声明；如果需要使用，补充使用逻辑；如果是有意保留，可加 (void)变量名; 消除警告。
📝 代码示例：
  错误：int x = 5;   // x 从未使用
  修复：删除该行，或添加 (void)x;

❌ 错误 4/7（警告）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 位置：main.cpp:15:1
📝 原始：error: control reaches end of non-void function [-Wreturn-type]
💡 中文解释：
  非 void 函数缺少 return 语句。函数声明了返回类型，但某些代码路径（特别是条件分支中）没有 return 语句。这会导致未定义行为！
🔧 修复建议：
  检查函数的所有代码路径，确保每个分支都有 return 语句。特别注意 if-else、switch 等条件语句。
📝 代码示例：
  错误：int func(int x) {
          if (x > 0) return 1;
          // x <= 0 时没有 return
        }
  正确：int func(int x) {
          if (x > 0) return 1;
          return 0;   // 添加默认 return
        }

❌ 错误 6/7（链接错误）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 位置：main.cpp:0
📝 原始：error: error: undefined reference to `func(int)'
💡 中文解释：
  函数或变量未定义。代码中有声明（头文件中），但链接器找不到对应的实现（定义）。常见原因：①函数只声明未实现；②实现文件未加入编译；③函数签名（参数类型）与声明不一致；④C++ 函数在 C 文件中实现导致名字修饰不匹配。
🔧 修复建议：
  1. 确认函数/变量有对应的实现代码
  2. 确认实现文件（.cpp）已加入编译命令
  3. 检查函数签名（参数类型、const 修饰）是否与声明完全一致
  4. 如果是 C/C++ 混合，使用 extern "C" 包裹 C 函数声明
📝 代码示例：
  // 声明（头文件）
  void func(int x);
  // 实现（.cpp 文件）— 必须存在且签名一致
  void func(int x) { /* ... */ }
  // 编译时必须包含实现文件：g++ main.cpp func.cpp
