## 四、子网拆分计算法

### 例题：把 192.168.1.0/24 拆成 4 个等大子网

1. 需要 4 个子网 → 需要借 2 位主机位（2^2 = 4）
2. 新前缀 = 24 + 2 = 26
3. 每个子网块大小 = 256 / 4 = 64
4. 子网列表：
   - 子网 0: 192.168.1.0/26（0~63）
   - 子网 1: 192.168.1.64/26（64~127）
   - 子网 2: 192.168.1.128/26（128~191）
   - 子网 3: 192.168.1.192/26（192~255）

### 公式

- 借 n 位主机位 → 得到 2^n 个子网
- 每个子网块大小 = 2^(8-n)（最后一个8位组）
- 子网掩码 = 255.255.255.(256 - 块大小)

## 五、VPC 网络规划建议

| 场景 | 建议 CIDR | 说明 |
|---|---|---|
| 小型 VPC（< 50 台主机） | 10.0.0.0/24 | 254 个可用地址 |
| 中型 VPC（50~500 台） | 10.0.0.0/22 | 1022 个可用地址 |
| 大型 VPC（500~5000 台） | 10.0.0.0/18 | 16382 个可用地址 |
| 多 AZ 子网 | 每个 AZ 一个 /24 | 便于扩展和管理 |

> 注意：VPC 子网不能重叠，且 VPC CIDR 不能与其他 VPC 或本地网络冲突。
