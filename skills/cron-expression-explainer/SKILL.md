# Cron 表达式解析助手

## 一、技能定位

本技能用于**解析、解释、验证和预测 cron 表达式**。核心价值：

- 解析标准 5 字段 cron 表达式（分 时 日 月 周）
- 用中文通俗解释每个字段的含义和取值
- 验证表达式合法性（检查越界、非法字符、语法错误）
- 生成未来 N 次执行时间（精确到分钟）
- 支持快捷写法（@yearly、@monthly、@weekly、@daily、@hourly、@midnight）
- 生成人类可读描述（如"每天上午9点30分"、"每周一至周五下午6点"）
- 支持范围（1-5）、列表（1,3,5）、步长（*/5）等高级语法
- 支持自定义起始时间和生成数量
- 内置常用 cron 表达式速查表

## 二、触发场景

当用户出现以下需求时使用本技能：

1. 用户说「这个 cron 表达式是什么意思」「解释一下 cron」
2. 用户说「cron 表达式验证」「这个 cron 对不对」
3. 用户说「这个 cron 什么时候执行」「下次执行时间」
4. 用户说「生成 cron 表达式」「每天9点的 cron 怎么写」
5. 用户说「cron 表达式速查」「常用 cron 写法」
6. 用户说「@daily 是什么意思」「cron 快捷写法」
7. 用户说「这个定时任务的执行时间对不对」
8. 用户说「cron 表达式报错」「invalid cron expression」

## 三、Cron 表达式基础

### 3.1 标准 5 字段格式

```
┌───────────── 分钟 (0 - 59)
│ ┌───────────── 小时 (0 - 23)
│ │ ┌───────────── 日 (1 - 31)
│ │ │ ┌───────────── 月 (1 - 12)
│ │ │ │ ┌───────────── 星期 (0 - 6，0=周日)
│ │ │ │ │
* * * * *
```

| 字段 | 允许值 | 允许特殊字符 |
|---|---|---|
| 分钟 | 0-59 | `*` `,` `-` `/` |
| 小时 | 0-23 | `*` `,` `-` `/` |
| 日 | 1-31 | `*` `,` `-` `/` `?` `L` `W` |
| 月 | 1-12 或 JAN-DEC | `*` `,` `-` `/` |
| 星期 | 0-6 或 SUN-SAT | `*` `,` `-` `/` `?` `L` `#` |

### 3.2 特殊字符说明

| 字符 | 含义 | 示例 |
|---|---|---|
| `*` | 任意值（每个单位） | `* * * * *` = 每分钟 |
| `,` | 值列表 | `1,3,5 * * * *` = 第1、3、5分钟 |
| `-` | 范围 | `1-5 * * * *` = 第1到5分钟 |
| `/` | 步长 | `*/5 * * * *` = 每5分钟 |
| `?` | 不指定（日或星期） | `0 0 * * ?` = 每天0点（不限制星期） |
| `L` | 最后一天/最后一个星期 | `0 0 L * *` = 每月最后一天 |
| `W` | 最近工作日 | `0 0 15W * *` = 每月15日最近的工作日 |
| `#` | 第几个星期几 | `0 0 * * 1#2` = 每月第二个周一 |

### 3.3 快捷写法

| 快捷写法 | 等价表达式 | 含义 |
|---|---|---|
| `@yearly` / `@annually` | `0 0 1 1 *` | 每年1月1日0点 |
| `@monthly` | `0 0 1 * *` | 每月1日0点 |
| `@weekly` | `0 0 * * 0` | 每周日0点 |
| `@daily` / `@midnight` | `0 0 * * *` | 每天0点 |
| `@hourly` | `0 * * * *` | 每小时0分 |

## 四、操作步骤

### 步骤 1：确认需求

确认用户需要：
- cron 表达式（要解析/验证/预测的表达式）
- 操作类型（解释 explain / 验证 validate / 预测 next / 全部 all）
- 生成数量（预测未来多少次执行，默认 10 次）
- 起始时间（从什么时候开始预测，默认当前时间）

### 步骤 2：运行脚本

使用 `scripts/explain_cron.py`：

```bash
# 基本用法：解释 cron 表达式
python3 scripts/explain_cron.py --expr "30 9 * * *"

# 验证表达式合法性
python3 scripts/explain_cron.py --expr "30 9 * * *" --validate

# 预测未来执行时间
python3 scripts/explain_cron.py --expr "30 9 * * *" --next

# 预测指定次数
python3 scripts/explain_cron.py --expr "*/15 * * * *" --next --count 20

# 全部功能（解释+验证+预测）
python3 scripts/explain_cron.py --expr "0 18 * * 1-5" --all

# 快捷写法
python3 scripts/explain_cron.py --expr "@daily" --all

# 指定起始时间
python3 scripts/explain_cron.py --expr "0 9 * * 1" --next --start "2026-01-01 00:00"

# 列出常用表达式
python3 scripts/explain_cron.py --cheatsheet

# 列出所有快捷写法
python3 scripts/explain_cron.py --shortcuts
```

### 步骤 3：安全提示

1. 本技能只进行解析和计算，不修改任何系统 crontab
2. 预测的执行时间基于表达式逻辑，实际执行可能受系统负载、时区等影响
3. 星期字段中 0 和 7 都表示周日，脚本统一处理
4. 日和星期字段同时指定具体值时，为"或"关系（满足任一即触发）
5. `?` 字符仅在日和星期字段有效，表示"不指定"
6. 本脚本使用标准 5 字段 cron，不支持 Quartz 6/7 字段（含秒和年）
7. 时区：预测使用系统本地时区，crontab 通常也使用系统时区

## 五、常见场景处理

### 场景 1：解释复杂表达式
**用户**：「`*/5 9-17 * * 1-5` 是什么意思？」
**处理**：运行 `--expr "*/5 9-17 * * 1-5" --explain` → 输出"工作日（周一至周五）上午9点到下午5点，每5分钟执行一次"。

### 场景 2：验证表达式
**用户**：「`60 25 * * *` 这个 cron 对吗？」
**处理**：运行 `--expr "60 25 * * *" --validate` → 报错"分钟值60超出范围0-59，小时值25超出范围0-23"。

### 场景 3：预测执行时间
**用户**：「`0 9 * * 1` 下次什么时候执行？」
**处理**：运行 `--expr "0 9 * * 1" --next --count 5` → 输出未来5个周一上午9点的日期时间。

### 场景 4：快捷写法
**用户**：「@weekly 是什么意思？」
**处理**：运行 `--expr "@weekly" --all` → 等价于 `0 0 * * 0`，即每周日0点0分。

### 场景 5：生成表达式
**用户**：「每天下午6点的 cron 怎么写？」
**处理**：`0 18 * * *`（每天18点0分）。

### 场景 6：每月最后一天
**用户**：「每月最后一天执行的 cron？」
**处理**：`0 0 L * *`（每月最后一天0点），注意 `L` 在部分 cron 实现中可能不支持，通用写法可用脚本判断。

### 场景 7：工作日定时
**用户**：「工作日上午9点半执行？」
**处理**：`30 9 * * 1-5`（周一至周五9点30分）。

### 场景 8：每小时的第几分钟
**用户**：「每小时的第15和45分钟执行？」
**处理**：`15,45 * * * *`（每小时第15和45分钟）。

## 六、注意事项

1. **字段顺序**：标准 cron 是"分 时 日 月 周"，不要与 Quartz 的"秒 分 时 日 月 周"混淆。
2. **星期取值**：0 和 7 都表示周日，1=周一，...，6=周六。
3. **日与星期的关系**：同时指定日和星期的具体值时，为"或"关系（满足任一即触发）；使用 `?` 表示不限制该字段。
4. **步长语法**：`*/5` 表示从0开始每5个单位；`10-30/5` 表示10到30范围内每5个单位。
5. **L 字符**：`L` 在日字段表示当月最后一天，在星期字段表示当月最后一个星期几（如 `5L` = 最后一个周五）。
6. **W 字符**：`15W` 表示离15日最近的工作日（周一至周五），如果15日是周六则提前到14日，周日则延后到16日。
7. **# 字符**：`1#2` 表示每月第二个周一（星期#第几个）。
8. **时区**：cron 表达式使用系统本地时区，跨时区部署时需注意。
9. **不修改系统**：本技能只解析和预测，不写入 crontab，不执行任何命令。
10. **预测限制**：预测从指定起始时间开始，生成未来 N 次执行时间，最大支持 1000 次。
