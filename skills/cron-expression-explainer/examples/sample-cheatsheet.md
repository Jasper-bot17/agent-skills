# Cron 表达式速查表

> 覆盖日常运维、开发、系统管理中最常用的 cron 表达式写法。

---

## 一、基础格式

```
┌───────────── 分钟 (0 - 59)
│ ┌───────────── 小时 (0 - 23)
│ │ ┌───────────── 日 (1 - 31)
│ │ │ ┌───────────── 月 (1 - 12)
│ │ │ │ ┌───────────── 星期 (0 - 6，0=周日)
│ │ │ │ │
* * * * *
```

---

## 二、常用表达式

### 2.1 分钟级

| 描述 | 表达式 |
|---|---|
| 每分钟 | `* * * * *` |
| 每5分钟 | `*/5 * * * *` |
| 每10分钟 | `*/10 * * * *` |
| 每15分钟 | `*/15 * * * *` |
| 每30分钟 | `*/30 * * * *` |
| 每小时第0分钟 | `0 * * * *` |
| 每小时第30分钟 | `30 * * * *` |
| 每小时第15和45分钟 | `15,45 * * * *` |

### 2.2 小时级

| 描述 | 表达式 |
|---|---|
| 每小时 | `0 * * * *` |
| 每2小时 | `0 */2 * * *` |
| 每3小时 | `0 */3 * * *` |
| 每6小时 | `0 */6 * * *` |
| 每天0点（午夜） | `0 0 * * *` |
| 每天上午6点 | `0 6 * * *` |
| 每天上午9点 | `0 9 * * *` |
| 每天上午9点30分 | `30 9 * * *` |
| 每天中午12点 | `0 12 * * *` |
| 每天下午6点 | `0 18 * * *` |
| 每天晚上10点 | `0 22 * * *` |
| 每天上午9点和下午6点 | `0 9,18 * * *` |
| 每天6点、12点、18点 | `0 6,12,18 * * *` |

### 2.3 工作日/周末

| 描述 | 表达式 |
|---|---|
| 工作日（周一至周五）上午9点 | `0 9 * * 1-5` |
| 工作日下午6点 | `0 18 * * 1-5` |
| 工作日上午9点到下午5点每小时 | `0 9-17 * * 1-5` |
| 周末（周六周日）上午10点 | `0 10 * * 0,6` |
| 每周一上午9点 | `0 9 * * 1` |
| 每周五下午6点 | `0 18 * * 5` |
| 每周日0点 | `0 0 * * 0` |
| 每周三凌晨2点 | `0 2 * * 3` |

### 2.4 月度

| 描述 | 表达式 |
|---|---|
| 每月1日0点 | `0 0 1 * *` |
| 每月1日上午9点 | `0 9 1 * *` |
| 每月15日0点 | `0 0 15 * *` |
| 每月最后一天0点 | `0 0 L * *` |
| 每月1日和15日0点 | `0 0 1,15 * *` |
| 每季度第一天0点 | `0 0 1 1,4,7,10 *` |

### 2.5 年度

| 描述 | 表达式 |
|---|---|
| 每年1月1日0点 | `0 0 1 1 *` |
| 每年1月1日上午8点 | `0 8 1 1 *` |
| 每年12月31日晚上11点50分 | `50 23 31 12 *` |
| 每年生日（假设3月15日） | `0 9 15 3 *` |

## 三、快捷写法

| 快捷写法 | 等价表达式 | 含义 |
|---|---|---|
| `@yearly` / `@annually` | `0 0 1 1 *` | 每年1月1日0点 |
| `@monthly` | `0 0 1 * *` | 每月1日0点 |
| `@weekly` | `0 0 * * 0` | 每周日0点 |
| `@daily` / `@midnight` | `0 0 * * *` | 每天0点 |
| `@hourly` | `0 * * * *` | 每小时0分 |

---

## 四、特殊字符

| 字符 | 含义 | 示例 |
|---|---|---|
| `*` | 任意值 | `* * * * *` = 每分钟 |
| `,` | 值列表 | `1,3,5 * * * *` = 第1、3、5分钟 |
| `-` | 范围 | `1-5 * * * *` = 第1到5分钟 |
| `/` | 步长 | `*/5 * * * *` = 每5分钟 |
| `?` | 不指定（日或星期） | `0 0 * * ?` = 每天0点 |
| `L` | 最后一天/星期 | `0 0 L * *` = 每月最后一天 |
| `W` | 最近工作日 | `0 0 15W * *` = 每月15日最近工作日 |
| `#` | 第几个星期几 | `0 0 * * 1#2` = 每月第二个周一 |

## 五、常见场景

### 5.1 系统运维
- 日志轮转：`0 0 * * *`（每天0点）
- 备份数据库：`0 2 * * *`（每天凌晨2点）
- 清理临时文件：`0 3 * * 0`（每周日凌晨3点）
- 系统更新检查：`0 8 * * 1`（每周一上午8点）
- 磁盘空间监控：`*/30 * * * *`（每30分钟）

### 5.2 开发/CI
- 每日构建：`0 0 * * *`（每天0点）
- 每周构建：`0 0 * * 1`（每周一0点）
- 代码扫描：`0 1 * * 1-5`（工作日凌晨1点）
- 依赖更新检查：`0 9 * * 1`（每周一上午9点）

### 5.3 数据处理
- 数据同步：`*/15 * * * *`（每15分钟）
- 报表生成：`0 8 1 * *`（每月1日上午8点）
- 数据备份：`0 2 * * *`（每天凌晨2点）
- 日志归档：`0 0 1 * *`（每月1日0点）

### 5.4 通知提醒
- 每日站会提醒：`0 9 * * 1-5`（工作日上午9点）
- 周报提醒：`0 17 * * 5`（每周五下午5点）
- 月度总结：`0 9 1 * *`（每月1日上午9点）
- 生日提醒：`0 9 15 3 *`（每年3月15日上午9点）

## 六、注意事项

1. **时区**：cron 使用系统本地时区，跨时区部署时需注意。
2. **星期编号**：0 和 7 都表示周日，1=周一，...，6=周六。
3. **日与星期**：同时指定日和星期的具体值时，为"或"关系（满足任一即触发）。
4. **L 字符**：在日字段表示当月最后一天，在星期字段表示当月最后一个星期几。
5. **W 字符**：`15W` 表示离15日最近的工作日，周末会顺延到最近的周一/周五。
6. **# 字符**：`1#2` 表示每月第二个周一（星期#第几个）。
7. **环境变量**：cron 环境的 PATH 可能与交互式 shell 不同，建议使用绝对路径。
8. **输出重定向**：建议将输出重定向到日志文件，如 `* * * * * /path/to/script >> /var/log/script.log 2>&1`。
9. **避免重叠**：如果任务可能运行超过间隔时间，使用锁文件防止重叠执行。
10. **测试**：修改 crontab 后，先用 `crontab -l` 确认，再观察第一次执行结果。
