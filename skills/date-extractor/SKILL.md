# 日期提取与倒计时助手

## 一、技能定位

本技能用于**从任意文本中自动提取日期和截止事项，并生成倒计时清单**。核心价值：

- 自动识别：从邮件、会议记录、文档中识别所有日期
- 多格式支持：YYYY-MM-DD、YYYY/MM/DD、中文日期（2024年3月15日）、相对日期（下周、月底）
- 倒计时计算：自动计算距离今天还有多少天
- 上下文关联：提取日期周围的文字，说明"这是什么事的截止"
- 智能排序：按时间先后排序，突出即将到来的事项
- 逾期提醒：已过期的事项单独标注

## 二、触发场景

当用户出现以下需求时使用本技能：

1. 用户说「帮我从这段文字里找出所有日期/截止时间」
2. 用户说「帮我看看还有哪些事快到截止了」
3. 用户说「这些文档里有哪些 deadline」
4. 用户说「帮我整理一下会议纪要里的时间节点」
5. 用户说「距离某个截止日期还有多少天」
6. 用户说「帮我从邮件里提取待办事项和时间」
7. 用户说「最近有哪些事情要到期了」
8. 用户给出一段文本，要求"找出日期""提取截止时间""生成倒计时"

## 三、支持的日期格式

### 3.1 标准日期

| 格式 | 示例 |
|---|---|
| YYYY-MM-DD | 2024-03-15 |
| YYYY/MM/DD | 2024/03/15 |
| YYYY.MM.DD | 2024.03.15 |
| YYYYMMDD | 20240315 |

### 3.2 中文日期

| 格式 | 示例 |
|---|---|
| 完整中文 | 2024年3月15日 |
| 简短中文 | 3月15日 |
| 中文+星期 | 3月15日星期五 |

### 3.3 相对日期

| 格式 | 示例 | 说明 |
|---|---|---|
| 今天/明天/后天 | 明天截止 | 相对今天 |
| X天后 | 3天后提交 | 相对今天 |
| 本周/下周 | 周五前提交 | 本周工作日 |
| 月底/月初 | 月底前完成 | 本月最后一天 |
| 本周X | 本周三 | 本周星期几 |

### 3.4 时间表达式

| 格式 | 示例 |
|---|---|
| 带时间 | 2024-03-15 14:00 |
| 上午/下午 | 3月15日下午 |
| 截止/deadline | 截止日期：2024-03-15 |

## 四、操作步骤

### 步骤 1：接收文本

确认用户输入的文本来源：
- 直接粘贴的文本
- 文件路径（.txt/.md/.docx 等文本文件）
- 邮件内容
- 会议记录

### 步骤 2：运行提取脚本

使用 `scripts/extract_dates.py` 进行日期提取：

```bash
# 从文件提取日期
python3 scripts/extract_dates.py --file notes.txt

# 直接传入文本
python3 scripts/extract_dates.py --text "报告截止3月15日，下周开会"

# 从 stdin 读取
cat notes.txt | python3 scripts/extract_dates.py

# 只显示未来30天内的事项
python3 scripts/extract_dates.py --file notes.txt --within-days 30

# 包含已过期事项
python3 scripts/extract_dates.py --file notes.txt --include-overdue

# 输出 JSON 格式
python3 scripts/extract_dates.py --file notes.txt --output json
```

### 步骤 3：解读提取结果

脚本输出包含：

```
📅 日期与截止事项清单
━━━━━━━━━━━━━━━━━━
分析日期：2026-09-20
共发现 5 个日期事项

⏳ 即将到来（按时间排序）：
  🔴 3天后（09-23 周二）
     提交季度报告
     来源："报告截止3月15日"

  🟡 7天后（09-27 周六）
     项目演示
     来源："下周三演示"

  🟢 14天后（10-04 周六）
     团队聚餐
     来源："月底前团建"

⚠ 已过期：
  🔴 已过期 2 天
     月度总结
     来源："9月18日前提交"
```

### 步骤 4：与用户确认

1. **日期是否准确**：有没有识别错误的日期？
2. **上下文是否完整**：提取的事项描述是否清楚？
3. **相对日期计算**：相对日期（下周/月底）的计算是否合理？
4. **是否遗漏**：有没有文本中提到但未识别的日期？

### 步骤 5：输出最终清单

根据用户确认后输出：
- 按时间排序的截止事项
- 倒计时天数
- 事项描述
- 重要事项标注

## 六、常见场景处理

### 场景 1：整理会议纪要中的截止事项
**用户**：「帮我从这份会议纪要里找出所有要做的事和截止时间」
**处理**：运行提取脚本 → 输出所有日期事项 → 按时间排序 → 标注即将到期的。

### 场景 2：追踪项目 deadline
**用户**：「这个项目还有哪些 deadline 快到了」
**处理**：提取所有日期 → 筛选未来14天内 → 输出紧急程度排序。

### 场景 3：从邮件中提取待办
**用户**：「帮我看看这封邮件里有什么时间要求」
**处理**：粘贴邮件内容 → 提取日期 → 输出截止事项。

### 场景 4：生成倒计时清单
**用户**：「帮我做个本月待办倒计时清单」
**处理**：提取文本中所有日期 → 按时间排序 → 标注重要事项。

## 七、注意事项

1. **相对日期需确认**：相对日期（下周、月底）基于今天计算，可能存在歧义，需与用户确认。
2. **年份推断**：没有年份的日期默认按当前年份；如果月份已过，可能需要推断为下一年。
3. **上下文提取**：日期周围的文字不一定完整描述事项，可能需要结合上下文理解。
4. **多种日期格式**：同一文本可能混用多种格式，脚本尽量兼容，但复杂格式可能遗漏。
5. **时区问题**：脚本不处理时区，默认按本地日期计算。
6. **不替代日历**：本工具用于从文本中提取日期，不是日历管理工具。
7. **重复日期合并**：同一日期的多个事项会分别列出，不会自动合并。
8. **模糊日期**：如"过几天""不久后"等模糊表达无法精确计算，会标注为模糊。
9. **跨年处理**：12月提到的"1月"可能是下一年1月，脚本会尝试推断。
10. **隐私保护**：文本内容不离开本地，提取过程在本地完成。
