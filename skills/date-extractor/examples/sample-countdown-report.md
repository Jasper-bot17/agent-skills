# 示例：日期提取与倒计时报告

> 本示例展示使用 `extract_dates.py` 对 `sample-notes.txt` 进行分析的输出。
> 示例为一份项目会议纪要，包含多种日期格式和截止事项。

---

## 输入文本摘要

```
项目会议纪要 - 2026-09-20

1. 提交季度报告 - 截止9月23日（本周二）
2. 回复客户合同 - 今天内完成
3. 修复登录bug - 明天前上线
4. 项目演示准备 - 下周三
5. 团队团建 - 月底前安排
6. 产品发布会 - 10月15日
7. Q3总结会议 - 2026年10月10日
8. 月度数据报表 - 9月18日前提交（已逾期）
```

---
