# 个人记账与消费分析助手

## 一、技能定位

本技能用于**个人和家庭的日常收支记录与消费分析**。核心价值：

- 降低记账门槛：用户用自然语言描述消费即可，AI 自动解析金额、类别、日期
- 自动分类：根据消费描述智能匹配消费类别，无需手动选择
- 可视化报告：按月/周生成消费报告，包含分类占比、趋势对比、预算执行
- 异常识别：标记超出常规的大额支出或异常消费
- 省钱建议：基于消费数据给出可操作的节省建议

## 二、触发场景

当用户出现以下需求时使用本技能：

1. 用户说「帮我记一笔账」「今天花了XX钱」「午餐35元」等记账需求
2. 用户提供消费记录（文本、CSV、截图），要求整理或分析
3. 用户说「帮我看看这个月花了多少钱」「生成月度消费报告」「分析一下我的消费」
4. 用户说「我这个月预算超了吗」「帮我看看哪里花多了」「有什么省钱建议」
5. 用户需要将散乱的消费记录整理成结构化的表格
6. 用户说「帮我做个记账模板」「设置每月预算」

## 四、操作步骤

### 步骤 1：接收并解析消费记录

根据用户输入形式选择处理方式：

**方式 A：自然语言单笔记账**
用户输入如「今天午餐35元」「打车回家28块」「买了件衣服299」。
AI 解析出：日期、金额、类别、描述、支付方式（如有）。

**方式 B：批量文本记录**
用户提供多行消费记录，如：
```
9/1 早餐 8
9/1 地铁 6
9/1 午餐 35
9/2 超市 156.5
```
AI 逐行解析，统一格式。

**方式 C：CSV/表格文件**
用户提供 CSV 或 Excel 文件，使用 `scripts/analyze_expenses.py` 解析。
```bash
python3 scripts/analyze_expenses.py --input expenses.csv --format report
```

**方式 D：消费截图**
用户提供账单截图（支付宝/微信/银行），AI 通过 OCR 识别消费记录。

### 步骤 2：自动分类

对每笔消费进行类别匹配：

1. **关键词匹配**：根据消费描述中的关键词匹配二级类别
   - 「午餐/吃饭/外卖/咖啡」→ 餐饮
   - 「地铁/打车/加油/机票」→ 交通
   - 「衣服/口红/面膜/手机」→ 购物
   - 「房租/水电/物业」→ 住房
   - 「电影/游戏/旅游/健身」→ 娱乐
2. **金额辅助判断**：结合金额范围辅助分类（如大额「衣服」更可能是购物而非餐饮）
3. **商家名称识别**：识别常见商家名称（星巴克→餐饮，滴滴→交通，淘宝→购物）
4. **无法确定时**：归入「其他」类别，并在报告中标注建议用户确认

### 步骤 3：数据结构化

将所有消费记录整理为统一格式：

| 字段 | 说明 | 示例 |
|---|---|---|
| 日期 | YYYY-MM-DD | 2026-09-01 |
| 金额 | 数值（支出为正，收入为负或单独标记） | 35.00 |
| 类型 | 支出/收入 | 支出 |
| 一级类别 | 标准类别 | 餐饮 |
| 二级类别 | 细分类别 | 午餐 |
| 描述 | 原始消费描述 | 公司楼下快餐 |
| 支付方式 | 微信/支付宝/现金/信用卡（可选） | 微信 |
| 备注 | 用户补充信息（可选） | 客户请客 |

### 步骤 4：使用辅助脚本分析（推荐）

对于批量数据，使用 `scripts/analyze_expenses.py` 进行统计分析：

```bash
# 生成月度消费报告（文本格式）
python3 scripts/analyze_expenses.py --input expenses.csv --month 2026-09 --format report

# 输出 JSON 格式（供后续处理）
python3 scripts/analyze_expenses.py --input expenses.csv --month 2026-09 --format json

# 设置预算进行预算执行分析
python3 scripts/analyze_expenses.py --input expenses.csv --month 2026-09 --budget 8000

# 按周统计
python3 scripts/analyze_expenses.py --input expenses.csv --week 2026-W37
```

脚本输出包含：
- 总支出/总收入/结余
- 各分类支出金额和占比
- 每日支出趋势
- 最大单笔支出 Top 5
- 预算执行情况（如设置了预算）
- 与上月对比（如有上月数据）

### 步骤 5：生成消费报告

根据分析结果生成结构化报告，包含以下章节：

1. **本月概览**：总收入、总支出、结余、日均支出
2. **分类占比**：各一级类别支出金额和占比（饼图描述）
3. **消费趋势**：每日/每周支出走势，标注高峰日
4. **大额支出**：Top 5 单笔支出及占总支出比例
5. **预算执行**：各分类预算 vs 实际，超支标记
6. **异常提醒**：超出常规范围的消费类别或单笔
7. **省钱建议**：基于数据的可操作建议（如「餐饮占比42%，建议减少外卖」）
8. **下月预算建议**：基于本月数据给出下月各分类预算参考

### 步骤 6：质量自检

- [ ] 每笔消费的金额是否准确（与原始记录一致）？
- [ ] 类别分类是否合理？不确定的是否标注「待确认」？
- [ ] 日期是否正确解析（相对日期如「昨天」「上周五」是否转换为具体日期）？
- [ ] 收入和支出是否区分清楚？
- [ ] 总金额计算是否正确（用工具核算，不手算）？
- [ ] 报告中的百分比是否与金额一致？
- [ ] 省钱建议是否基于实际数据，而非泛泛而谈？
- [ ] 是否保护了用户隐私（不在报告中暴露完整卡号等敏感信息）？

## 六、常见场景处理

### 场景 1：自然语言记账
**用户**：「今天中午吃了个麻辣烫32，下午买了杯奶茶18」
**处理**：解析为两笔记录，分别归类为「餐饮 > 午餐」和「餐饮 > 零食饮料」，确认后记录。

### 场景 2：批量导入
**用户**：粘贴一个月的消费记录文本，说「帮我整理一下这个月的消费」
**处理**：逐行解析 → 自动分类 → 生成结构化表格 → 输出月度报告。

### 场景 3：月度复盘
**用户**：「帮我分析一下8月份的消费，看看哪里花多了」
**处理**：读取8月数据 → 分类统计 → 识别超支类别 → 给出针对性建议。

### 场景 4：预算控制
**用户**：「我这个月预算5000，帮我看看还能花多少」
**处理**：计算已支出 → 剩余预算 → 按剩余天数计算日均可用额度 → 提醒超支类别。

### 场景 5：消费趋势
**用户**：「帮我看看最近三个月的消费趋势」
**处理**：按月汇总 → 生成趋势对比表 → 分析变化原因（如某月有大额旅游支出）。

## 七、预算参考标准

根据用户收入水平提供合理的预算分配参考（50/30/20 法则为基础）：

| 类别 | 建议占比 | 说明 |
|---|---|---|
| 必要支出（住房+餐饮+交通+通讯+医疗） | 50% | 生活必需 |
| 弹性支出（购物+娱乐+教育+人情） | 30% | 可调节 |
| 储蓄/理财 | 20% | 强制储蓄 |

**注意**：以上为通用参考，实际预算应根据用户所在城市、收入水平、家庭状况个性化调整。AI 应基于用户历史数据给出建议，而非机械套用比例。

## 八、注意事项

1. **金额准确性**：所有金额计算必须使用工具（calculator 或脚本），禁止心算。报告中的合计、占比、平均值必须可复现。
2. **不编造数据**：用户未提供的消费记录不得自行补充。缺失数据明确标注。
3. **日期解析**：相对日期（「昨天」「上周」「月初」）必须基于当前实际日期转换，禁止凭记忆推断。
4. **隐私保护**：报告中不暴露完整银行卡号、身份证号等敏感信息；消费描述中的敏感信息（如医院名称涉及隐私）可适当脱敏。
5. **分类歧义**：一笔消费可能属于多个类别时（如「买了本编程书」既可算教育也可算购物），选择最主要的类别，并在备注中说明。
6. **收入处理**：收入单独统计，不与支出混在一起。结余 = 收入 - 支出。
7. **退款/报销**：退款和报销记为收入或冲减对应类别支出，需在备注中标注。
8. **不提供投资建议**：本技能只做消费记录和分析，不提供具体的投资、理财、金融产品建议。
9. **数据持久化**：本技能不自动保存用户数据到外部。如用户需要长期记账，建议导出为 CSV 文件保存，或使用专门的记账 App。

## 十、使用示例

### 示例 1：快速记账
**用户**：「刚打车花了26块」
**AI**：解析为 2026-09-13 交通 > 打车 ¥26.00，确认记录，更新本月累计。

### 示例 2：批量记录+月度报告
**用户**：粘贴30行消费记录，说「帮我整理成表格并分析一下」
**AI**：逐行解析 → 自动分类 → 输出明细表 → 生成月度消费报告（含分类占比、趋势、大额支出、省钱建议）。

### 示例 3：预算检查
**用户**：「我每月预算6000，这个月还剩多少可以花？」
**AI**：读取本月已记录支出 → 计算剩余预算 → 按剩余天数计算日均额度 → 提醒已超支类别。

### 示例 4：CSV 分析
**用户**：上传 expenses.csv，说「帮我分析一下这个文件里的消费」
**AI**：使用脚本解析 CSV → 自动分类补全 → 生成统计报告 → 输出可视化描述和建议。
