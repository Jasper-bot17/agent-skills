# HTTP 状态码排查速查指南

> http-status-codes 技能配套指南。

---

## 一、状态码分类总览

| 分类 | 含义 | 常见场景 |
|---|---|---|
| 1xx | 信息性响应 | 协议切换、处理中、早期提示 |
| 2xx | 成功 | 请求成功、资源创建、部分内容 |
| 3xx | 重定向 | 永久/临时跳转、缓存验证 |
| 4xx | 客户端错误 | 参数错误、未授权、未找到、限流 |
| 5xx | 服务端错误 | 服务器崩溃、网关错误、超时 |

---

## 二、高频状态码排查流程图

```
收到 HTTP 响应
    │
    ├── 2xx？→ 正常处理
    │
    ├── 3xx？→ 检查 Location 头，跟随跳转
    │         ├── 301/308 → 永久迁移，更新书签
    │         ├── 302/307 → 临时跳转，保持原 URL
    │         └── 304 → 使用缓存
    │
    ├── 4xx？→ 客户端问题
    │         ├── 400 → 检查请求格式/参数
    │         ├── 401 → 检查认证令牌
    │         ├── 403 → 检查权限
    │         ├── 404 → 检查 URL
    │         ├── 429 → 降低频率，等待重试
    │         └── 其他 → 查看具体错误信息
    │
    └── 5xx？→ 服务端问题
              ├── 500 → 查看服务器日志
              ├── 502 → 检查后端服务是否运行
              ├── 503 → 服务维护/过载，稍后重试
              └── 504 → 后端处理超时，优化性能
```

## 三、常见对比

### 401 vs 403

| 对比项 | 401 Unauthorized | 403 Forbidden |
|---|---|---|
| 含义 | 未登录/令牌无效 | 已登录但权限不足 |
| 解决 | 提供有效认证 | 申请更高权限 |
| 响应头 | WWW-Authenticate | 通常无特殊头 |

### 301 vs 302 vs 307 vs 308

| 对比项 | 301 | 302 | 307 | 308 |
|---|---|---|---|---|
| 永久性 | 永久 | 临时 | 临时 | 永久 |
| 保持方法 | 否（POST→GET） | 否（POST→GET） | 是 | 是 |
| 缓存 | 浏览器缓存 | 不缓存 | 不缓存 | 浏览器缓存 |

### 502 vs 504

| 对比项 | 502 Bad Gateway | 504 Gateway Timeout |
|---|---|---|
| 含义 | 上游返回无效响应 | 上游未在超时时间内响应 |
| 原因 | 后端崩溃/格式错误 | 后端处理过慢 |
| 排查 | 检查后端是否运行 | 检查慢查询/性能 |

## 四、最佳实践

1. **不要泛捕获 500**：应根据具体状态码做不同处理
2. **429 必须重试**：使用指数退避，不要立即重试
3. **304 利用缓存**：条件请求可节省带宽
4. **4xx 不重试**：客户端错误重试无意义
5. **5xx 谨慎重试**：可能是临时故障，但避免雪崩
6. **记录状态码**：在日志中记录响应状态码便于排查
