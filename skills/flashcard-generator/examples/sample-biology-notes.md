# 细胞的能量供应与利用 — 学习笔记

## 一、酶

### 1.1 酶的定义
酶是指活细胞产生的具有催化作用的有机物，其中绝大多数酶是蛋白质，少数酶是RNA（核酶）。

### 1.2 酶的特性
酶的特性包括：高效性、专一性、作用条件较温和。

- 高效性：酶的催化效率大约是无机催化剂的10^7～10^13倍。
- 专一性：一种酶只能催化一种或一类化学反应。
- 作用条件较温和：酶所催化的化学反应一般在比较温和的条件下进行。

### 1.3 酶的作用机理
酶的作用机理是降低化学反应的活化能。分子从常态转变为容易发生化学反应的活跃状态所需要的能量称为活化能。酶通过降低活化能，使反应在温和条件下快速进行。

### 1.4 影响酶活性的因素
影响酶活性的因素主要有温度和pH值。

- 温度：在最适温度下，酶的活性最高。温度过高会使酶的空间结构遭到破坏，使酶永久失活；低温使酶的活性降低，但不会失活，温度恢复后活性可恢复。
- pH：在最适pH下，酶的活性最高。pH过高或过低都会使酶的空间结构遭到破坏，使酶永久失活。

## 二、ATP

### 2.1 ATP的定义
ATP（三磷酸腺苷）是指细胞内的一种高能磷酸化合物，是细胞生命活动的直接能源物质。

### 2.2 ATP的结构
ATP的结构简式为A-P～P～P，其中A代表腺苷，P代表磷酸基团，～代表高能磷酸键。ATP分子中大量的能量就储存在高能磷酸键中。

### 2.3 ATP与ADP的相互转化
ATP与ADP的相互转化是时刻不停地发生并且处于动态平衡之中的。

- ATP水解：ATP → ADP + Pi + 能量（释放的能量用于各项生命活动）
- ATP合成：ADP + Pi + 能量 → ATP（能量来自呼吸作用和光合作用）

### 2.4 ATP的功能
ATP的功能是为细胞的各项生命活动直接提供能量，如肌肉收缩、神经传导、物质运输、细胞分裂、生物发电等。

## 三、细胞呼吸

### 3.1 细胞呼吸的定义
细胞呼吸是指有机物在细胞内经过一系列的氧化分解，生成二氧化碳或其他产物，释放出能量并生成ATP的过程。

### 3.2 有氧呼吸
有氧呼吸是指细胞在氧的参与下，通过多种酶的催化作用，把葡萄糖等有机物彻底氧化分解，产生二氧化碳和水，释放能量，生成大量ATP的过程。

有氧呼吸的过程分为三个阶段：

第一阶段：1分子葡萄糖分解成2分子丙酮酸，产生少量的[H]，释放少量能量，场所是细胞质基质。

第二阶段：丙酮酸和水彻底分解成二氧化碳和[H]，释放少量能量，场所是线粒体基质。

第三阶段：前两个阶段产生的[H]与氧结合生成水，释放大量能量，场所是线粒体内膜。

总反应式：C6H12O6 + 6H2O + 6O2 →(酶) 6CO2 + 12H2O + 能量

### 3.3 无氧呼吸
无氧呼吸是指细胞在无氧条件下，通过多种酶的催化作用，把葡萄糖等有机物不彻底地氧化分解，产生酒精和二氧化碳或乳酸，释放少量能量，生成少量ATP的过程。

无氧呼吸的过程分为两个阶段：

第一阶段：与有氧呼吸第一阶段完全相同，场所是细胞质基质。

第二阶段：丙酮酸在不同酶的催化作用下，分解成酒精和二氧化碳，或者转化成乳酸，场所是细胞质基质。

### 3.4 有氧呼吸和无氧呼吸的区别
有氧呼吸和无氧呼吸的区别主要体现在以下几个方面：需要氧气、主要场所、分解产物、释放能量多少、ATP产量。

- 有氧呼吸需要氧气，主要场所是线粒体，产物是CO2和H2O，释放大量能量，产生约30-32个ATP。
- 无氧呼吸不需要氧气，场所是细胞质基质，产物是酒精+CO2或乳酸，释放少量能量，产生2个ATP。

### 3.5 细胞呼吸的意义
细胞呼吸的意义在于为生物体的各项生命活动提供能量，为体内其他化合物的合成提供原料（如中间产物丙酮酸），维持体温。

## 四、光合作用

### 4.1 光合作用的定义
光合作用是指绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成储存能量的有机物，并且释放氧气的过程。

### 4.2 光合作用的发现历程
光合作用的发现经历了以下重要阶段：

1771年，普利斯特利发现植物可以更新因蜡烛燃烧或小鼠呼吸而变污浊的空气。
1779年，英格豪斯发现普利斯特利的实验只有在阳光照射下才能成功，植物体只有绿叶才能更新污浊的空气。
1864年，萨克斯证明光合作用的产物除氧气外还有淀粉。
1939年，鲁宾和卡门利用同位素标记法证明光合作用释放的氧气来自水。
1948年，卡尔文探明了CO2中的碳在光合作用中转化成有机物中碳的途径（卡尔文循环）。

### 4.3 光合作用的过程
光合作用的过程分为光反应和暗反应两个阶段。

光反应阶段：
- 场所：叶绿体类囊体薄膜上
- 条件：必须有光
- 物质变化：水的光解（2H2O → 4[H] + O2）；ATP的合成（ADP + Pi + 光能 → ATP）
- 能量变化：光能 → ATP中活跃的化学能

暗反应阶段（卡尔文循环）：
- 场所：叶绿体基质中
- 条件：有光无光都能进行（但需要光反应提供的[H]和ATP）
- 物质变化：CO2的固定（CO2 + C5 → 2C3）；C3的还原（2C3 → (CH2O) + C5，需要[H]、ATP、酶）
- 能量变化：ATP中活跃的化学能 → 有机物中稳定的化学能

### 4.4 光合作用的总反应式
光合作用的总反应式为：6CO2 + 6H2O —(光能/叶绿体)→ C6H12O6 + 6O2

### 4.5 影响光合作用的因素
影响光合作用的因素包括光照强度、CO2浓度、温度、水分、矿质元素等。

- 光照强度：在一定范围内，光合作用强度随光照强度的增加而增加，达到光饱和点后不再增加。
- CO2浓度：在一定范围内，光合作用强度随CO2浓度的增加而增加。
- 温度：温度通过影响酶的活性来影响光合作用，在最适温度时光合作用最强。
