# 记忆卡片生成助手

## 一、技能定位

本技能用于**将学习材料转化为可高效复习的记忆卡片**。核心价值：

- 自动从文本中提取核心知识点，无需手动逐张制作卡片
- 生成多种类型的高质量问答卡片，覆盖不同记忆需求
- 导出为 Anki 等主流记忆软件兼容格式，可直接导入
- 提供间隔重复复习安排，提升记忆效率
- 支持对已有卡片进行质量评估和优化建议

## 二、触发场景

当用户出现以下需求时使用本技能：

1. 用户提供学习笔记/教材/文章，说「帮我做几张记忆卡片」「生成 flashcard」「把这段内容做成问答题」
2. 用户说「我要备考XX，帮我从这些资料里提取知识点做卡片」
3. 用户需要将读书笔记转化为可复习的问答卡片
4. 用户说「帮我生成 Anki 卡片」「导出可以导入 Anki 的文件」
5. 用户需要对某一主题进行系统复习，要求生成覆盖全面的卡片组
6. 用户说「帮我安排一下这些卡片的复习计划」「间隔重复怎么安排」

## 三、卡片类型体系

### 3.1 概念定义型
**适用**：术语、定义、理论、专有名词
**格式**：
- 正面：「什么是 XXX？」「XXX 的定义是什么？」
- 背面：完整定义 + 关键特征 + 举例

### 3.2 因果关系型
**适用**：原因与结果、条件与结论、机制与效应
**格式**：
- 正面：「XXX 的原因是什么？」「XXX 会导致什么结果？」
- 背面：原因/机制 + 结果 + 关键中间环节

### 3.3 对比辨析型
**适用**：易混淆概念、相似理论、不同方法的区别
**格式**：
- 正面：「XXX 和 YYY 的区别是什么？」
- 背面：对比表格或分点对比（定义、特点、适用场景、优缺点）

### 3.4 公式定理型
**适用**：数学公式、物理定律、化学方程式、算法复杂度
**格式**：
- 正面：「XXX 公式是什么？」「XXX 定理的内容？」
- 背面：公式/定理 + 各符号含义 + 适用条件 + 典型例题

### 3.5 步骤流程型
**适用**：操作步骤、实验流程、算法步骤、代谢途径
**格式**：
- 正面：「XXX 的步骤是什么？」「简述 XXX 的过程」
- 背面：编号步骤 + 每步关键要点 + 注意事项

### 3.6 列举型
**适用**：特征、分类、优缺点、影响因素
**格式**：
- 正面：「XXX 的主要特征有哪些？」「XXX 分为哪几类？」
- 背面：编号列表 + 每项简要说明

### 3.7 时间线型
**适用**：历史事件、发展历程、阶段划分
**格式**：
- 正面：「XXX 的发展历程？」「XXX 经历了哪些阶段？」
- 背面：时间线（时间 - 事件 - 意义）

### 3.8 填空型（cloze）
**适用**：关键术语、数字、人名、年份
**格式**：
- 正面：「{{c1::XXX}} 是指……」（Anki cloze 格式）
- 背面：完整句子 + 被填内容的解释

## 四、操作步骤

### 步骤 1：读取并理解学习材料

1. 完整读取用户提供的文本（笔记、教材章节、文章、PDF 提取文本等）
2. 如果文本过长，分段读取，确保不遗漏关键知识点
3. 识别文本的主题领域（如医学、法律、计算机、历史、语言等），调整卡片风格
4. 识别文本结构：标题层级、定义段落、公式、列表、案例等

### 步骤 2：提取核心知识点

从文本中提取以下类型的知识点：

| 知识点类型 | 提取线索 |
|---|---|
| 定义/概念 | 「是指」「定义为」「称为」「XXX是」 |
| 原因/机制 | 「因为」「由于」「导致」「机制是」「原理」 |
| 对比/区别 | 「区别于」「不同于」「相比」「与…的区别」 |
| 公式/定理 | 数学公式、「定理」「定律」「法则」 |
| 步骤/流程 | 「第一步」「首先」「然后」「流程」「步骤」 |
| 特征/分类 | 「特征」「特点」「分为」「包括」「类型」 |
| 优缺点 | 「优点」「缺点」「优势」「局限」「不足」 |
| 时间/事件 | 年份、「在…时期」「经历了」「发展」 |

**提取原则**：
- 优先提取考试/应用中高频的核心知识点
- 每个知识点应能独立成一张卡片
- 避免提取过于琐碎或显而易见的内容
- 一张卡片只聚焦一个知识点（避免「卡片过载」）

### 步骤 3：使用辅助脚本初步提取（可选）

对于较长的文本，可使用 `scripts/generate_flashcards.py` 进行初步的知识点提取和卡片生成：

```bash
# 从文本文件生成卡片（文本格式输出）
python3 scripts/generate_flashcards.py --input notes.txt --format text

# 输出 Anki 兼容 CSV（正面,背面,标签）
python3 scripts/generate_flashcards.py --input notes.txt --format anki

# 输出 JSON 格式
python3 scripts/generate_flashcards.py --input notes.txt --format json

# 指定卡片数量和主题标签
python3 scripts/generate_flashcards.py --input notes.txt --max-cards 30 --tags "生物学,细胞"
```

脚本会基于模式匹配提取定义、列表、对比等知识点，生成初步卡片。**注意：脚本结果仅作辅助，必须经过 AI 语义审核和优化后才能作为最终卡片。**

### 步骤 4：AI 生成高质量卡片

基于提取的知识点，为每个知识点生成卡片：

#### 4.1 选择卡片类型
根据知识点性质选择最合适的卡片类型（参见第三节卡片类型体系）。

#### 4.2 编写正面（问题）
- 问题明确、具体，无歧义
- 避免「关于XXX，以下说法正确的是」这类模糊问题
- 一个问题只问一个知识点
- 语言简洁，不超过 30 字（中文）

#### 4.3 编写背面（答案）
- 答案准确、完整，基于原文不编造
- 关键信息用加粗或编号突出
- 适当补充举例、口诀、记忆技巧
- 复杂内容用表格或分点呈现
- 标注信息来源（如「出自教材第3章」）

#### 4.4 添加标签
为每张卡片添加标签，便于分类复习：
- 学科/领域标签：如「医学」「法律」「计算机」
- 主题标签：如「心血管系统」「合同法」「数据结构」
- 难度标签：如「基础」「进阶」「高频考点」
- 卡片类型标签：如「定义」「对比」「公式」

### 步骤 5：卡片质量自检

生成卡片后，逐项检查：

- [ ] 每张卡片只聚焦一个知识点？
- [ ] 正面问题是否明确、无歧义？
- [ ] 背面答案是否准确、完整（与原文一致，不编造）？
- [ ] 是否避免了「卡片过载」（一张卡片内容过多）？
- [ ] 是否有重复或高度相似的卡片？
- [ ] 卡片类型是否匹配知识点性质？
- [ ] 关键术语、数字、人名是否准确？
- [ ] 标签是否合理，便于分类复习？
- [ ] 整体卡片是否覆盖了文本的核心知识点（覆盖率 ≥ 80%）？

### 步骤 6：生成复习计划（如用户需要）

基于间隔重复（Spaced Repetition）原理，生成复习安排：

| 复习阶段 | 时间间隔 | 说明 |
|---|---|---|
| 初次学习 | Day 0 | 当天学习新卡片 |
| 第一次复习 | Day 1 | 次日复习 |
| 第二次复习 | Day 3 | 间隔2天 |
| 第三次复习 | Day 7 | 间隔4天 |
| 第四次复习 | Day 14 | 间隔1周 |
| 第五次复习 | Day 30 | 间隔2周 |
| 长期保持 | 每30天 | 已掌握卡片定期回顾 |

- 标记为「困难」的卡片：缩短间隔（Day 0 → 1 → 2 → 4 → 7 → 14）
- 标记为「简单」的卡片：延长间隔（Day 0 → 3 → 7 → 14 → 30 → 60）
- 每天复习量建议：新卡片 ≤ 20 张/天，复习卡片 ≤ 100 张/天

### 步骤 7：导出与交付

1. **Markdown 格式**：直接在对话中展示卡片（适合快速预览）
2. **Anki CSV 格式**：生成 `正面,背面,标签` 格式的 CSV 文件，可直接导入 Anki
3. **JSON 格式**：结构化数据，便于程序处理
4. 如用户需要，可创建飞书文档或导出为文件

## 五、输出规范

### 5.1 Markdown 卡片展示格式

```markdown
### 卡片 1：[概念定义] 什么是细胞呼吸？

**正面（问题）**：
什么是细胞呼吸？其本质是什么？

**背面（答案）**：
细胞呼吸是指**有机物在细胞内经过一系列氧化分解，生成二氧化碳或其他产物，释放能量并生成ATP的过程**。

- **本质**：氧化分解有机物，释放能量
- **主要场所**：线粒体（有氧呼吸）
- **关键产物**：ATP（细胞的直接能源物质）
- **意义**：为细胞的各项生命活动提供能量

**标签**：`生物学` `细胞` `基础` `定义`

---
```

### 5.2 Anki CSV 格式

```csv
正面,背面,标签
"什么是细胞呼吸？","细胞呼吸是指有机物在细胞内经过一系列氧化分解...","生物学::细胞::基础"
"有氧呼吸和无氧呼吸的区别是什么？","| 对比项 | 有氧呼吸 | 无氧呼吸 |...","生物学::细胞::对比"
```

**注意**：Anki 导入时选择「逗号分隔」，字段映射为「正面=字段1，背面=字段2，标签=字段3」。

## 六、常见场景处理

### 场景 1：教材章节生成卡片
**用户**：上传一章教材 PDF，说「帮我把这章内容做成记忆卡片」
**处理**：提取文本 → 识别核心知识点 → 按章节结构组织卡片 → 生成 20-40 张卡片 → 导出 Anki CSV。

### 场景 2：考试备考重点卡片
**用户**：「我下周要考XX，帮我从这些笔记里提取高频考点做卡片」
**处理**：优先提取高频考点、易混淆点、公式定理 → 标记「高频考点」标签 → 生成 15-25 张核心卡片 → 提供 7 天复习计划。

### 场景 3：语言学习词汇卡片
**用户**：「帮我把这些英语单词做成记忆卡片」
**处理**：为每个单词生成「单词+音标+词性+释义+例句+记忆技巧」卡片 → 支持 cloze 填空格式 → 按主题/难度分组。

### 场景 4：读书笔记卡片
**用户**：「我读完了《XX》，帮我做几张卡片记住核心观点」
**处理**：提取核心观点、关键概念、金句、作者论证逻辑 → 生成 10-20 张卡片 → 标注书籍来源。

### 场景 5：技术知识学习卡片
**用户**：「帮我把这篇关于React Hooks的文章做成卡片」
**处理**：提取核心概念（useState/useEffect等）、使用规则、常见陷阱、代码示例 → 生成概念+对比+代码示例卡片 → 标签标记技术栈。

## 七、间隔重复复习指南

### 7.1 复习方法
1. **主动回忆**：看正面问题，先在脑中回忆答案，再翻背面核对
2. **诚实评分**：按「忘记/模糊/记住/熟练」四级评分
3. **困难卡片优先**：每天先复习标记为「困难」的卡片
4. **批量复习**：每天固定时间复习，保持节奏

### 7.2 记忆技巧
- **联想记忆**：将抽象概念与熟悉的事物关联
- **口诀记忆**：为列举类知识点编口诀
- **图像记忆**：为复杂过程画流程图（卡片背面可附简图描述）
- **间隔重复**：按复习计划定期回顾，避免临时抱佛脚

### 7.3 注意事项
- 不要一次制作过多卡片（每天新卡片 ≤ 20 张）
- 定期清理已熟练掌握的卡片（减少复习负担）
- 卡片内容要准确，错误的卡片比没有卡片更有害
- 结合实际应用（做题、实践）效果更佳

## 八、注意事项

1. **不编造知识**：卡片内容必须严格基于用户提供的材料，不得自行添加未提及的知识点或答案。如材料中信息不足，标注「待补充」。
2. **准确性优先**：涉及数字、公式、人名、年份等关键信息时，必须与原文核对，确保准确。
3. **卡片不过载**：一张卡片只聚焦一个知识点，避免把多个问题塞进一张卡片。
4. **问题要具体**：避免「关于XXX，说说你的理解」这类过于宽泛的问题。
5. **难度分层**：根据知识点的重要性和难度，合理分配基础/进阶/高频考点标签。
6. **隐私保护**：如学习材料涉及个人隐私或敏感信息，在卡片中适当脱敏。
7. **不替代专业指导**：本技能生成的卡片用于辅助学习，不构成专业教学或考试保证。
8. **可定制性**：如用户对卡片数量、难度、类型有特殊要求，按用户要求调整。

## 十、使用示例

### 示例 1：从笔记生成卡片
**用户**：粘贴一段关于「光合作用」的笔记，说「帮我做5张记忆卡片」
**AI**：提取核心知识点 → 生成 5 张卡片（定义、过程、对比、公式、意义）→ Markdown 展示 → 提供 Anki CSV 下载。

### 示例 2：批量生成 + 复习计划
**用户**：上传一章教材，说「帮我生成卡片并安排两周复习计划」
**AI**：提取 25 个核心知识点 → 生成 25 张卡片 → 导出 Anki CSV → 生成 14 天复习计划表（每天新卡片+复习卡片数量）。

### 示例 3：仅生成高频考点
**用户**：「从这些法律条文中提取最可能考的10个点做卡片」
**AI**：识别高频考点（定义、构成要件、例外情形、对比）→ 生成 10 张标记「高频考点」的卡片 → 附记忆口诀。

### 示例 4：优化已有卡片
**用户**：提供一组自制卡片，说「帮我看看这些卡片质量怎么样，怎么改进」
**AI**：逐张评估（问题明确性、答案完整性、卡片过载、重复）→ 给出改进建议 → 生成优化后的卡片。
