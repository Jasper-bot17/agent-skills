# 记忆卡片格式模板

> 本模板包含 8 种卡片类型的标准格式和示例，用于生成高质量记忆卡片。

---

## 通用格式

### Markdown 展示格式

```markdown
### 卡片 N：[类型标签] 卡片标题

**正面（问题）**：
<问题内容>

**背面（答案）**：
<答案内容，关键信息用**加粗**>

**标签**：`标签1` `标签2` `标签3`

---
```

### Anki CSV 格式

```csv
正面,背面,标签
"<问题内容>","<答案内容（HTML格式，支持<br>换行、<b>加粗、<table>表格）>","学科::主题::难度"
```

### JSON 格式

```json
{
  "id": 1,
  "type": "concept",
  "front": "问题内容",
  "back": "答案内容",
  "tags": ["标签1", "标签2"],
  "difficulty": "basic",
  "source": "教材第3章"
}
```

## 类型 1：概念定义型

**适用场景**：术语、定义、理论、专有名词

**模板**：
- 正面：「什么是 XXX？」「XXX 的定义是什么？」
- 背面：完整定义 + 关键特征（3-5点）+ 举例 + 易混淆点

**示例**：

```markdown
### 卡片 1：[概念定义] 什么是光合作用？

**正面（问题）**：
什么是光合作用？其总反应式是什么？

**背面（答案）**：
光合作用是指**绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成储存能量的有机物（主要是淀粉），并且释放氧气的过程**。

**总反应式**：
6CO₂ + 6H₂O —(光能/叶绿体)→ C₆H₁₂O₆ + 6O₂

**关键特征**：
- 场所：叶绿体
- 条件：光能
- 原料：CO₂ 和 H₂O
- 产物：有机物（糖类）和 O₂
- 能量转化：光能 → 化学能

**标签**：`生物学` `光合作用` `基础` `定义`
```

## 类型 2：因果关系型

**适用场景**：原因与结果、条件与结论、机制与效应

**模板**：
- 正面：「XXX 的原因是什么？」「XXX 会导致什么结果？」「XXX 的机制是？」
- 背面：原因/机制（分点）→ 中间环节 → 最终结果 → 影响因素

**示例**：

```markdown
### 卡片 2：[因果关系] 为什么会发生温室效应？

**正面（问题）**：
温室效应产生的原因和机制是什么？

**背面（答案）**：
**原因**：大气中温室气体（CO₂、CH₄、N₂O 等）浓度增加。

**机制**：
1. 太阳短波辐射穿过大气层到达地面
2. 地面吸收热量后以长波辐射（红外线）形式向外释放
3. 温室气体强烈吸收地面长波辐射
4. 温室气体再以辐射方式向四面八方释放热量，其中一部分返回地面
5. 地面和低层大气温度升高

**结果**：全球气候变暖、海平面上升、极端天气增多

**主要温室气体**：CO₂（贡献最大）、甲烷、氧化亚氮、氟利昂

**标签**：`环境科学` `气候变化` `因果` `进阶`
```

## 类型 3：对比辨析型

**适用场景**：易混淆概念、相似理论、不同方法的区别

**模板**：
- 正面：「XXX 和 YYY 的区别是什么？」
- 背面：对比表格（对比维度逐项对比）+ 记忆口诀

**示例**：

```markdown
### 卡片 3：[对比辨析] 有氧呼吸和无氧呼吸的区别

**正面（问题）**：
有氧呼吸和无氧呼吸的主要区别是什么？

**背面（答案）**：

| 对比项 | 有氧呼吸 | 无氧呼吸 |
|---|---|---|
| 是否需要O₂ | 需要 | 不需要 |
| 主要场所 | 线粒体（主要） | 细胞质基质 |
| 分解产物 | CO₂ + H₂O | 酒精+CO₂ 或 乳酸 |
| 释放能量 | 大量（约2870kJ/mol） | 少量（约196.65kJ/mol） |
| ATP产量 | 约30-32个 | 2个 |
| 发生生物 | 大多数动植物 | 乳酸菌、酵母菌（兼性） |

**共同点**：
- 第一阶段完全相同（糖酵解，在细胞质基质进行）
- 本质都是氧化分解有机物，释放能量

**记忆口诀**：有线粒体氧充足，无氧只在基质里，产酒产乳酸，能量只够塞牙缝。

**标签**：`生物学` `细胞呼吸` `对比` `高频考点`
```

## 类型 4：公式定理型

**适用场景**：数学公式、物理定律、化学方程式、算法复杂度

**模板**：
- 正面：「XXX 公式/定理是什么？」
- 背面：公式/定理 + 各符号含义 + 适用条件 + 典型例题

**示例**：

```markdown
### 卡片 4：[公式定理] 牛顿第二定律

**正面（问题）**：
牛顿第二定律的内容和公式是什么？各符号含义？

**背面（答案）**：
**内容**：物体加速度的大小跟作用力成正比，跟物体的质量成反比，加速度的方向跟作用力的方向相同。

**公式**：**F = ma**

**符号含义**：
- F：合外力（单位：牛顿 N）
- m：物体质量（单位：千克 kg）
- a：加速度（单位：m/s²）

**适用条件**：
- 惯性参考系中
- 宏观低速物体（相对论效应可忽略）
- F 为合外力（所有外力的矢量和）

**典型例题**：
质量为 2kg 的物体受到 10N 的合外力，求加速度？
解：a = F/m = 10/2 = 5 m/s²

**标签**：`物理学` `力学` `公式` `基础`
```

## 类型 5：步骤流程型

**适用场景**：操作步骤、实验流程、算法步骤、代谢途径

**模板**：
- 正面：「XXX 的步骤/过程是什么？」
- 背面：编号步骤 + 每步关键要点 + 注意事项

**示例**：

```markdown
### 卡片 5：[步骤流程] 有丝分裂的过程

**正面（问题）**：
简述有丝分裂各时期的主要特征。

**背面（答案）**：
有丝分裂分为**间期**和**分裂期**（前、中、后、末）：

**1. 间期**（占时最长）：
- DNA 复制和有关蛋白质合成
- 染色体呈染色质状态

**2. 前期**：
- 染色质螺旋化形成染色体
- 核膜、核仁逐渐消失
- 纺锤体形成

**3. 中期**：
- 染色体的着丝点排列在赤道板上
- 染色体形态最清晰，是观察染色体的最佳时期

**4. 后期**：
- 着丝点分裂，姐妹染色单体分开
- 染色体在纺锤丝牵引下移向两极

**5. 末期**：
- 染色体解螺旋为染色质
- 核膜、核仁重新出现
- 纺锤体消失
- 细胞质分裂（植物：细胞板；动物：缢裂）

**记忆口诀**：膜仁消失现两体（前），形定数晰赤道齐（中），点裂数加均两极（后），两消两现重开始（末）。

**标签**：`生物学` `细胞分裂` `步骤` `高频考点`
```

## 类型 6：列举型

**适用场景**：特征、分类、优缺点、影响因素

**模板**：
- 正面：「XXX 的主要特征/分类/优缺点有哪些？」
- 背面：编号列表 + 每项简要说明 + 记忆口诀

**示例**：

```markdown
### 卡片 6：[列举] 生物多样性的三个层次

**正面（问题）**：
生物多样性包括哪三个层次？各自的含义是什么？

**背面（答案）**：
生物多样性包括三个层次：

**1. 遗传多样性（基因多样性）**：
- 指同种生物不同个体之间的基因差异
- 是物种多样性和生态系统多样性的基础
- 例：不同品种的水稻

**2. 物种多样性**：
- 指一定区域内生物种类的丰富程度
- 是最直观、最基本的多样性
- 例：森林中有多种鸟类、昆虫、植物

**3. 生态系统多样性**：
- 指生态系统类型的多样性
- 包括森林、草原、湿地、海洋等
- 是生物多样性的最高层次

**三者关系**：遗传多样性 → 物种多样性 → 生态系统多样性（由微观到宏观）

**记忆口诀**：基因物种生态系，由小到大三层级。

**标签**：`生物学` `生物多样性` `列举` `基础`
```

## 类型 7：时间线型

**适用场景**：历史事件、发展历程、阶段划分

**模板**：
- 正面：「XXX 的发展历程/经历了哪些阶段？」
- 背面：时间线表格（时间 - 事件 - 意义）

**示例**：

```markdown
### 卡片 7：[时间线] 细胞学说的建立过程

**正面（问题）**：
简述细胞学说建立的主要历程和关键人物。

**背面（答案）**：

| 时间 | 人物 | 贡献 | 意义 |
|---|---|---|---|
| 1665年 | 罗伯特·胡克 | 用显微镜观察木栓组织，发现并命名"细胞" | 首次发现细胞 |
| 1680年 | 列文虎克 | 用自制显微镜观察到活细胞（细菌、原生动物等） | 首次观察活细胞 |
| 1838年 | 施莱登 | 提出"所有植物都是由细胞构成的" | 植物细胞学说 |
| 1839年 | 施旺 | 提出"所有动物也是由细胞构成的" | 建立细胞学说 |
| 1858年 | 魏尔肖 | 提出"细胞通过分裂产生新细胞" | 完善细胞学说 |

**细胞学说主要内容**：
1. 细胞是一个有机体，一切动植物都由细胞发育而来
2. 细胞是一个相对独立的单位
3. 新细胞可以从老细胞中产生

**标签**：`生物学` `细胞学说` `时间线` `基础`
```

## 类型 8：填空型（Cloze）

**适用场景**：关键术语、数字、人名、年份（Anki cloze 格式）

**模板**：
- 正面：包含 {{c1::答案}} 的完整句子
- 背面：完整句子 + 被填内容的解释

**示例**：

```markdown
### 卡片 8：[填空] DNA 结构

**正面（问题）**：
DNA 分子是由 {{c1::两条}} 链组成的，按 {{c2::反向平行}} 方式盘旋成 {{c3::双螺旋}} 结构。基本骨架由 {{c4::脱氧核糖和磷酸}} 交替连接构成，排列在 {{c5::外侧}}；碱基排列在 {{c6::内侧}}，通过 {{c7::氢键}} 连接。

**背面（答案）**：
完整句子：DNA 分子是由两条链组成的，按反向平行方式盘旋成双螺旋结构。基本骨架由脱氧核糖和磷酸交替连接构成，排列在外侧；碱基排列在内侧，通过氢键连接。

**关键考点**：
- 提出者：沃森和克里克（1953年）
- 碱基配对：A-T（2个氢键），G-C（3个氢键）
- 结构特点：稳定性、多样性、特异性

**标签**：`生物学` `DNA` `填空` `高频考点`
```

## 卡片质量检查清单

生成卡片后，逐项确认：

- [ ] 每张卡片只聚焦一个知识点
- [ ] 正面问题明确、具体、无歧义
- [ ] 背面答案准确、完整（与原文一致）
- [ ] 关键信息已加粗或编号突出
- [ ] 无重复或高度相似的卡片
- [ ] 卡片类型匹配知识点性质
- [ ] 标签合理（学科::主题::难度）
- [ ] 整体覆盖核心知识点（≥80%）
- [ ] 无编造内容（所有答案基于提供的材料）
