# 参考文献引用格式规范指南

> 覆盖 GB/T 7714-2015、APA 7th、MLA 9th、Chicago 四种常用引用格式。

---

## 一、GB/T 7714-2015（中国国家标准）

中国学术写作最常用的格式，采用**顺序编码制**。

### 1.1 期刊文章 [J]

```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**示例**：
```
[1] 张三, 李四. 深度学习研究[J]. 计算机学报, 2024, 47(3): 100-110.
[2] Smith J, Johnson A. AI research[J]. Journal of AI, 2024, 10(2): 1-10.
```

### 1.2 书籍 [M]

```
[序号] 作者. 书名[M]. 版本. 出版地: 出版者, 出版年: 起止页码.
```

**示例**：
```
[3] 王五. 机器学习导论[M]. 2版. 北京: 清华大学出版社, 2023: 50-80.
```

### 1.3 网页 [EB/OL]

```
[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

**示例**：
```
[4] 赵六. 人工智能发展报告[EB/OL]. (2024-01-15)[2024-06-01]. https://example.com/report.
```

### 1.4 学位论文 [D]

```
[序号] 作者. 题名[D]. 出版地: 学校, 年.
```

**示例**：
```
[5] 钱七. 基于深度学习的图像识别研究[D]. 北京: 清华大学, 2024.
```

### 1.5 会议论文 [C]

```
[序号] 作者. 题名[C]//会议名. 会议地点, 年: 起止页码.
```

**示例**：
```
[6] 孙八. 神经网络优化方法[C]//国际计算机会议. 北京, 2024: 50-60.
```

### 1.6 报纸文章 [N]

```
[序号] 作者. 题名[N]. 报纸名, 出版日期(版次): 页码.
```

**示例**：
```
[7] 周九. 科技发展新趋势[N]. 人民日报, 2024-03-15(3): A1.
```

### 1.7 报告 [R]

```
[序号] 作者. 题名[R]. 报告编号. 出版地: 机构, 年.
```

**示例**：
```
[8] 某研究所. 2024年度研究报告[R]. 2024-001. 北京: 某研究所, 2024.
```

### 1.8 专利 [P]

```
[序号] 发明者. 专利题名[P]. 专利国别: 专利号, 发布日期.
```

**示例**：
```
[9] 吴十. 一种智能算法: 中国, CN1234567A[P]. 2024-01-01.
```

### 1.9 作者规则

- 1-3 位作者：全部列出，用逗号分隔
- 3 位以上作者：列出前 3 位，后加"等"
- 中文作者：全名
- 英文作者：姓全拼，名缩写（如 Smith J）

## 二、APA 7th（美国心理学会）

社会科学常用格式，采用**作者-年份制**。

### 2.1 期刊文章

```
作者, A. A. (年). 题名. 刊名, 卷(期), 起止页码. https://doi.org/xxx
```

**示例**：
```
Smith, J., & Johnson, A. (2024). AI research. Journal of AI, 10(2), 1–10. https://doi.org/10.1234/ai
```

### 2.2 书籍

```
作者, A. A. (年). 书名 (版次 ed.). 出版社.
```

**示例**：
```
Smith, J. (2023). Machine learning (2nd ed.). MIT Press.
```

### 2.3 网页

```
作者, A. A. (年, 月 日). 题名. 网站名. URL
```

**示例**：
```
Smith, J. (2024, January 15). AI report. Example Site. https://example.com/report
```

### 2.4 学位论文

```
作者, A. A. (年). 题名 [Doctoral dissertation/Master's thesis, 学校]. 学校.
```

### 2.5 文中引用

- 1 位作者：`(Smith, 2024)`
- 2 位作者：`(Smith & Johnson, 2024)`
- 3 位以上：`(Smith et al., 2024)`
- 直接引用：`(Smith, 2024, p. 42)`

### 2.6 作者规则

- 最多列出 20 位作者，超过 20 位用"..."省略中间作者
- 姓全拼，名缩写（如 Smith, J.）
- 最后一位作者前加"&"

## 三、MLA 9th（现代语言协会）

人文学科常用格式，采用**作者-页码制**。

### 3.1 期刊文章

```
作者. "题名." 刊名, vol. 卷, no. 期, 年, pp. 起止页码.
```

**示例**：
```
Smith, John, and Alice Johnson. "AI Research." Journal of AI, vol. 10, no. 2, 2024, pp. 1-10.
```

### 3.2 书籍

```
作者. 书名. 版次 ed., 出版社, 年.
```

**示例**：
```
Smith, John. Machine Learning. 2nd ed., MIT Press, 2023.
```

### 3.3 网页

```
作者. "题名." 网站名, 发布日期, URL. Accessed 引用日期.
```

### 3.4 文中引用

- 1 位作者：`(Smith 42)`
- 2 位以上：`(Smith et al. 42)`
- 无作者：`("Title" 42)`

### 3.5 作者规则

- 1 位作者：姓, 名.
- 2 位作者：姓, 名, and 名 姓.
- 3 位以上：姓, 名, et al.

---

## 四、Chicago（芝加哥）

历史、艺术等人文学科常用，有**注释-书目制**和**作者-年份制**两种。本指南采用注释-书目制。

### 4.1 期刊文章

```
作者. "题名." 刊名 卷, no. 期 (年): 起止页码.
```

**示例**：
```
Smith, John, and Alice Johnson. "AI Research." Journal of AI 10, no. 2 (2024): 1-10.
```

### 4.2 书籍

```
作者. 书名. 版次. 出版地: 出版社, 年.
```

**示例**：
```
Smith, John. Machine Learning. 2nd ed. Cambridge: MIT Press, 2023.
```

### 4.3 网页

```
作者. "题名." 网站名. 发布日期. URL. (accessed 引用日期).
```

### 4.4 作者规则

- 1 位作者：姓, 名.
- 多位作者：第一位"姓, 名"，其余"名 姓"，最后一位前加"and"

---

## 五、格式选择建议

| 学科/场景 | 推荐格式 |
|---|---|
| 中文论文（国内期刊/学位论文） | GB/T 7714-2015 |
| 心理学、教育学、社会科学 | APA 7th |
| 文学、语言学、人文学科 | MLA 9th |
| 历史、艺术、哲学 | Chicago |
| 计算机科学（中文） | GB/T 7714-2015 |
| 计算机科学（英文） | APA 或 IEEE |

> 注意：不同学校/期刊可能有自定义格式要求，最终以目标要求为准。
