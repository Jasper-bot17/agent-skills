## 使用方式

每个技能都是一个独立目录，包含：

```
skill-name/
├── SKILL.md           # 技能定义（触发场景、使用说明）
├── scripts/           # 可执行脚本（Python，纯标准库无依赖）
├── templates/         # 模板与参考文档
└── examples/          # 示例与常用命令
```

将技能目录放到你的 Agent 技能目录下即可使用，平台无关。
