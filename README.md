# Agent Skills Collection

每日自动创建的实用 Agent 技能合集，共 19 个技能。

## 技能列表

| # | 技能名 | 类别 | 核心功能 |
|---|---|---|---|
| 1 | meeting-notes-organizer | 办公效率 | 会议纪要整理、行动项提取 |
| 2 | git-commit-message-generator | 开发提效 | Git 提交信息自动生成 |
| 3 | expense-tracker | 生活管理 | 个人记账与消费分析 |
| 4 | flashcard-generator | 学习辅助 | 记忆卡片生成与间隔复习 |
| 5 | file-organizer | 效率工具 | 文件目录扫描、分类、整理 |
| 6 | text-readability-analyzer | 内容创作 | 文本可读性分析与润色建议 |
| 7 | csv-data-cleaner | 数据处理 | CSV 数据清洗、去重、缺失值处理 |
| 8 | regex-tester | 开发工具 | 正则测试、解释、常用配方 |
| 9 | task-prioritizer | 时间管理 | 任务优先级排序、四象限分类 |
| 10 | date-extractor | 日程管理 | 日期提取、倒计时、截止事项追踪 |
| 11 | markdown-formatter | 文档工具 | Markdown 格式化、表格对齐、目录生成 |
| 12 | json-formatter | 数据工具 | JSON 格式化、校验、字段提取、差异比较 |
| 13 | log-analyzer | 运维工具 | 日志分析、错误统计、异常检测 |
| 14 | password-generator | 安全工具 | 密码生成、强度评估、策略合规检查 |
| 15 | env-manager | 开发运维 | 环境变量管理、多环境对比、配置审计 |
| 16 | backup-planner | 系统管理 | 备份计划生成、目录扫描、备份脚本输出 |
| 17 | compile-error-decoder | 开发学习 | 编译错误中文解码、修复建议、学习笔记 |
| 18 | snippet-manager | 开发工具 | 代码片段管理、搜索、Markdown/VS Code 导出 |
| 19 | color-palette-generator | 创意设计 | 配色方案生成、对比度检查、CSS/Tailwind 配置 |
